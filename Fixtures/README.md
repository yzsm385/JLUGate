## 黄金向量

```
digestA(0x004..0x013) = d030ec3cfa269619e0d3c3224b3e9aa6
digestA = MD5(0x03 ‖ 0x01 ‖ 49cb720f ‖ "test-pass-2024")
```

构造器产出的 342 字节，**除下列随机区外必须逐字节相等**：

| 区间 | 长度 | 含义 |
|---|---|---|
| `0x03A`..`0x04F` | 22 | 未知（每次随机） |
| `0x061`..`0x068` | 8 | 未知（每次随机） |
| `0x13A`..`0x143` | 10 | 未知（每次随机） |
| `0x144`..`0x145` | 2 | **常量** `02 0C` |
| `0x146`..`0x149` | 4 | 未知（每次随机） |
| `0x154`..`0x155` | 2 | 未知（每次随机） |

## 为什么可以公开

- 账号、密码是编的，`192.0.2.0/24` 与 `169.254.1.1` 是保留地址，MAC 带本地管理位；
- 摘要按新密码重算，**与真实凭据无关**；
- 原始 pcap 已从仓库移除，且 `.gitignore` 永久排除 `*.pcap` / `*.har`。

如果你要用自己的抓包做测试，**不要把 pcap 提交到仓库**；需要固化成夹具时，先按上面的方式替换身份字段并重算摘要。
