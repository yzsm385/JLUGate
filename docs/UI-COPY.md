> 这是 App 里**用户能看到的文字**，按界面分组，用来改写。
>
> - 每条前面的编号（`M03`、`B1-12` 这种）不要改——我按编号回填进代码；
> - `{…}` 是运行时填进去的值（账号、IP、端口、秒数、错误码…），位置可以挪，但别删；
> - 语气、长短随意，一条对应代码里的一处；改完把整份文件发我就行；
> - 没收进来的：纯日志行（agent.log 里的内容）、学院名单这类纯数据、程序内部用的英文与符号。

## 新生引导卡片

<sub>设置页顶部、向导里的「不会填？去自助平台查」。</sub>

- **G01** JLU.WIFI：不用填 IP / MAC
- **G02** 不会填？去校园网自助平台查
- **G03** 它是网页认证，地址由 DHCP 动态分配；用统一身份认证的账号密码在登录页登录。
- **G04** 先确认 Wi-Fi 名字就是 JLU.WIFI（大写、带点），别在同名的可疑网络里输账号。
- **G05** 固定 IP、网关在「查询信息」里；登记 MAC 在「变更 MAC」里。连不上也可能是网费欠了。
- **G06** 打开 ip.jlu.edu.cn/pay
- **G07** 收起
- **G08** 看步骤
- **G09** 连上 JLU.WIFI（名字要一模一样），菜单栏点图标 →「登录」，
- **G10** 在打开的网页里用统一身份认证的账号密码登录。
- **G11** 不用填 IP / 掩码 / 网关 / MAC——地址是动态分配的，网页认证只认账号。
- **G12** 自助平台只用来查网费、开户、看在线的设备。
- **G13** 用校园卡号（录取通知书上那串，如 20220501324）＋ 6 位数字密码 ＋ 验证码登录。
- **G14** 点「查询信息」：IP、网关、DNS 都在这儿——这里没有 MAC。
- **G15** 登记 MAC 走另一个入口：点「变更 MAC」进去看/改。
- **G16** 列表里没有你的 IP：回主菜单点「网络开户」，开通后再回来查。
- **G17** 三种密码
- **G18** 自己电脑的 MAC
- **G19** 如果其实是连 JLU.WIFI：这些静态参数一个都不用填，那是动态地址的网页认证。
- **G20** 吉大 V 卡（校园卡）
- **G21** 账号 = 录取通知书号；密码 = 6 位数字。自助平台用的是这套。
- **G22** 吉大邮箱
- **G23** 独立的一套密码，只用来登邮箱；账号格式和统一账号一样。
- **G24** 统一身份认证
- **G25** 教务、VPN、还有本 App（含 JLU.WIFI 网页登录）用的都是这套。
- **G26** 有线网卡
- **G27** 系统设置 → 网络 → 点那根有线（USB 网卡也在这）→ 详细信息 → MAC 地址。
- **G28** 系统设置 → Wi-Fi → 点已加入的网（JLU.WIFI / JLU.PC）旁的「⋯」→ MAC。
- **G29** 要的是这块网卡的物理地址。系统若开了「私有 Wi-Fi 地址 / 随机 MAC」，
- **G30** 先关掉它，或在 App 里勾「用登记的 MAC 认证」。
- **G31** 连不上，也可能是欠费
- **G32** -10 元、0 元都还能上；到 -20 元就断（有线 / JLU.PC / JLU.WIFI 都一样）。
- **G33** 充值档位只有 20 / 40 / 100，钱从校园卡余额扣——欠 20 时充 20 变成 0 不算数，
- **G34** 要充 40 让余额变成 20 才能用。
- **G35** 这些数字在自助平台「查询信息」里，用校园卡号 + 6 位 V 卡密码登录。
- **G36** 打开自助平台
- **G37** 新生看这里

## 校园网规则与提示

<sub>MAC 不符、私有 MAC、JLU.WIFI 名额等长说明。</sub>

- **B402** 未知
- **B403** 学校按 MAC 地址认设备：当前网卡{…} 是 {…}，而账号登记的是 {…}。 有线走的是网线/USB 网卡的 MAC，JLU.PC 走的是 Wi-Fi 网卡的 MAC，两者不是同一块卡、也不能互改。 要改用这个网络，得先到自助平台把登记 MAC 改成 {…}（改了以后原来那台就用不了了）。
- **B404** （读不到硬件地址）
- **B405** （未登记）
- **B406** 系统现在给这块网卡用的是私有/随机 MAC：{…}（第二位是 2/6/a/e 就属于这类）， 而网卡出厂地址是 {…}，学校登记的是 {…}。 三种处理方式： 1. 到「系统设置 → 网络 → 该网卡 → 详细信息 → 硬件」里把「私有地址/随机 MAC」关掉，恢复硬件地址； 2. 或在 App 设置里打开「用登记的 MAC 认证」（认证报文按登记值填，网卡本身不变）； 3. 或去 ip.jlu.edu.cn 把登记 MAC 改成当前这个随机地址（不推荐，换网会被系统再换一次）。
- **B407** JLU.PC 使用本机 Wi-Fi 网卡的 MAC 认证。若你在学校登记的是 USB/有线网卡的 MAC， 这里会认证失败——需要先到 ip.jlu.edu.cn 把登记 MAC 改成 Wi-Fi 网卡的（改完有线那台会失效）。

- **B409** 服务器认为这个 MAC 不属于你的账号。Mac 的 MAC 是网卡固化的，不能靠软件改： 请到 ip.jlu.edu.cn 核对/修改登记 MAC，或换回登记过的那块网卡。
- **B410** JLU.WIFI 同时最多 {…} 台设备，新设备加入会把最早加入的那台踢下线。 你的会话可能就是这样被挤掉的。
- **B411** 重新登录会把你排到队尾，并踢掉当前队列里第二台设备——如果那是你自己的另一台电脑/手机，它会掉线。
- **B412** 本机：{…} 台设备上限之外，登录会让你重新排到队尾。 {…}
- **B413** 连上新网络时弹出的网页是 macOS 的"捕获门户助手"，由系统触发，App 无法拦截。 如果它已经认证成功（本程序会尽快完成），它会自己关掉。
