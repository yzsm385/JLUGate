# 发布文案 · v0.1.0

## 主帖（论坛 / V2EX / 群）

**标题：给吉大同学写了个 Mac 原生校园网客户端，三种上网方式合成一个，顺手能体检**

Mac 上的校园网一直有点割裂：有线要 Dr.Com、JLU.PC 要 Dr.Com、JLU.WIFI 又是网页认证，
三个入口三套流程，账号密码还是同一套。

所以写了个原生 SwiftUI 菜单栏应用 **JLU Gate**：

- **原生，不是壳**：Swift 6 + SwiftUI，菜单栏常驻，没有 Electron、没有后台常开的浏览器内核，点开即用
- **快**：认证走 UDP 61440 直连网关，10 秒保活、掉线自动重连、休眠唤醒自动恢复；不是轮询式"看起来在线"
- **一次登录，三网通用**：账号密码填一次，之后自动连接，不再反复输入
- **不碰你的密码**：JLU.WIFI 用系统浏览器登录，程序只负责判断"通了没"
- **顺带能体检**（这部分挺实用）：
  - 到底能不能上网：Google / Brave / DDG / Bing / 百度 + 教务 / OA / 邮箱，逐站指出卡在 DNS、TCP、TLS 还是网站本身
  - 出口 IP 干不干净：多源交叉判断住宅还是机房（访问 Claude 这类站点前先看一眼）
  - WebRTC / DNS 泄漏 / Cloudflare 机房 / 人机验证可达性
  - 带宽三档：直连 vs 代理 vs 本地住宅代理

装完是一个盾牌图标待在菜单栏，不占 Dock。

下载：https://github.com/yzsm385/JLUGate/releases/tag/v0.1.0
（ad-hoc 签名，首次打开需要右键 → 打开）

只对校园网环境有意义；网卡被系统换成"私有 MAC"、代理接管路由这些坑，程序里都做了检测和提示。
