# JLU Gate 0.3.6

> 0.3.5 的日志证明：本机存着的是一串**从未成功登录过**的密码，而它一直被自动复用。

## 诊断里的关键三行

```
13:25:00  使用保存的密码（来源：已保存（未验证），10 字符 / 指纹 5c1e2749）
13:25:00  发送登录包：370 字节，摘要A=1013f605b34ae80c…
13:25:00  登录被服务器拒绝：错误码=0x15
```

- 指纹 `5c1e2749` ≠ 已知可用密码的指纹 `e20f4459`，也 ≠ 11-02 成功那次用的密码；
- 服务端对**两版报文**都回 `0x15`（凭据被拒），不是版本问题。

也就是说：程序一直拿这串"从没成功过"的密码去登录，你看到界面是点号，自然以为是自己刚输的。

## 这一版的规则

| 保存的密码状态 | 行为 |
|---|---|
| 成功登录过（verified） | 允许自动复用 |
| 从未成功 / 上次被拒（unverified） | **不自动使用**，直接打开向导要求重新输入 |

重新输入时：
- 出现第二个确认框，两次不一致会拦下（防全角/空格）；
- 显示本次密码指纹（长度 + 8 位），可与设置页的"已保存指纹"对照；
- 登录成功后写入 verified 标记；被拒则清掉。

## 你只需要做一件事

打开 0.3.6 → 点连接 → 它会直接让你**重新输入一次密码**（不会再偷偷用旧的）。
如果这样仍然 `0x15`，那就说明服务器认定的账号/密码不对，请用 `mails.jlu.edu.cn` 网页版验证；
把新日志的"指纹"行发我即可（不含密码）。
