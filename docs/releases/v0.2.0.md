## 用法

菜单栏面板底部「站点」→ 搜索或按分类浏览：

- **打开**：默认浏览器直接进；
- **复制账号 / 复制密码**：对需要登录的站点（邮箱、统一认证、教务、校务、WebVPN、自助服务）提供，
  打开时若已保存账号会自动把账号放进剪贴板，粘贴即可；
- 标注「仅校内」的站点在校外要先连 **WebVPN**；「需 VPN」表示页面能开、里面的资源要校园网。

密码只在点「复制密码」时从本机凭据库读出，不写日志、不上屏。
