## 怎么用

菜单栏面板底下有个「站点」，点进去可以搜，也能按分类逛：

- **打开**：直接用默认浏览器进；
- **复制账号 / 复制密码**：对需要登录的站点（邮箱、统一认证、教务、校务、WebVPN、自助服务）才有，
  打开时如果你存过账号，它会自动把账号放进剪贴板，粘贴一下就行；
- 标着「仅校内」的站点，在校外得先连上 **WebVPN**；标「需 VPN」的是页面能开、但里头的资源要校园网才用得了。

你的密码只在点「复制密码」那一下才会从本机凭据库里读出来，既不写进日志，也不会在屏幕上明文显示。
