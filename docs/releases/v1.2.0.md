# JLU Gate 1.2.0

> 新增「作息提醒」：到点提醒你睡觉、早八别迟到。**只按北京时间算**，跟系统时区无关。

## 为什么只按北京时间

有人把系统时区设成美国（或别的），按系统时间提醒就会错好几个小时。
这里直接用 UTC+8 判断（中国没有夏令时，常年不变），不管你在哪儿、系统怎么设，都按学校的作息来。

## 提醒规则

| 时间（北京时间） | 条件 | 提示 |
|---|---|---|
| 22:30–23:20 | 周日–周四 | 🌙 还有 N 分钟断电：存文件、给手机充电、准备睡觉 |
| 23:20–23:30 | 周日–周四 | 😴 只剩 N 分钟：赶紧保存、关灯、躺平 |
| 23:30–01:30 | 周日–周四 | 🌙 已经熄灯：屏幕光会晃到室友，早点休息 |
| 23:00–00:30 | 周五、周六 | 🎉 不断电，可以多玩会儿，但别熬太狠 |
| 07:30–08:30 | 周一–周五 | ☀️ 早八时间到：洗漱、买早餐、别迟到 |

提醒出现在主面板「登录」按钮下面，一条淡淡的彩色卡片，不挡操作、不弹窗。
简体 / 繁體 / English 三语都写了。

## 安装 / 升级

- macOS 14/15：`JLU-Gate-v1.2.0-Compat.zip`
