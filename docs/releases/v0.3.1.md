# JLU Gate 0.3.1

> 输入框换成 **SwiftUI 圆角框**（你要的那个样子），预填和快捷键都在，不崩。

- 每段一个 `TextField(.roundedBorder)`，段间是 `·` / `:`；
- **预填**：IP / 掩码 / 网关 / 登记 MAC 进入页面即带出（系统读数，DHCP 时橙色提示）；
- **快捷键**：输满自动跳段、Enter 跳下一段（最后一段=完成）、←/→ 跨段、⌫ 空段退回；
- 不再用自绘 AppKit 框，不需要维护字段编辑器状态，也就没有"每格只吃一个字符"的问题；
- 输入时只把结果写出去，外部改动（预填/清空/切档案）才回灌，避免互相覆盖。

连接路径：`DrcomCodec` / `PacketLayout` / `DrcomPacket` / `MD5` 与 0.2.2 一致，
引擎只保留"有线优先/选口排序"，不涉报文。
