# JLU Gate 0.3.1

> 输入框换成 **SwiftUI 圆角框**——就是你想要的样子，预填和快捷键都还在，也不崩。

- 每一段用一个 `TextField(.roundedBorder)`，段之间是 `·` / `:`；
- **预填**：IP / 掩码 / 网关 / 登记 MAC 一进页面就带出来（系统读数，DHCP 时用橙色提示）；
- **快捷键**：输满自动跳段、Enter 跳下一段（最后一段就是完成）、←/→ 跨段、⌫ 在空段退回；
- 不再用自绘的 AppKit 框，也就不用维护字段编辑器状态，"每格只吃一个字符"那种问题自然没了；
- 输入时只把结果写出去，只有外部改动（预填 / 清空 / 切档案）才回灌，免得互相覆盖。

连接路径：`DrcomCodec` / `PacketLayout` / `DrcomPacket` / `MD5` 跟 0.2.2 一致，
引擎只留着"有线优先/选口排序"，不碰报文。
