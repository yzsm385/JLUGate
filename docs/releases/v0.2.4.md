# JLU Gate 0.2.4

> 这版专治那个让人头疼的「已损坏，应移到废纸篓」——其实不是没签名，是签名在打包的时候被自己手滑弄坏了。

## 怎么坏的

先说清楚它怎么坏的：打包脚本的顺序搞反了。

```
1. codesign --force --sign -  ← 先签名
2. PlistBuddy 改 CFBundleVersion ← 再改 Info.plist
```

签名覆盖 Info.plist，改完之后签名就当场作废了。Gatekeeper 一比对，发现"签名里说的内容跟实际对不上"，报的就不是客客气气的"无法验证开发者"，而是直接甩一句**"已损坏，应移到废纸篓"**——就是你在新电脑上撞见的那个。

## 现在怎么打包的

现在顺序倒了过来，几个关键点：

- 先写 build 号，**最后**签名；
- 脚本里加了 `codesign --verify --strict` 作为构建闸门：签名无效就直接失败，不会做出坏包；
- 0.2.4 起的包都验证过 `Signature=adhoc` 且 `codesign --verify` 通过。

## 换到新电脑上，还会看到什么

因为**没有 Apple 开发者证书、也没公证**，第一次打开还是会拦你一下，但拦下来说的不再是「已损坏」，而是「无法验证开发者」，这就正常多了：

1. 右键点 `JLU Gate.app` → 打开 → 再点「打开」；
2. 或执行 `xattr -dr com.apple.quarantine "/Applications/JLU Gate.app"`。

（要彻底免掉这一步，需要 Developer ID 签名 + 公证，那需要 Apple 开发者账号。）
