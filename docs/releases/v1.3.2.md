# JLU Gate 1.3.2

> 修「明明开了开机自启，重启还是不启动」，外加首次打开底栏文字偏小的问题。

## 开机自启：真正的 bug 在这

以前**只有点设置页的「保存」**才会把 App 登记进系统登录项；App 自己每次启动时都不检查。
所以会出现：

- 设置里开关是开的、系统里其实没登记；
- 或者登记的是更新前的旧 App，换了新版本之后系统里那条记录对不上了。

现在每次启动都会对一遍：

- 配置里开着 → 确保系统里真的登记（`SMAppService` 状态会写进日志）；
- 配置里关着 → 注销；
- 更新完重新打开 App，也会自动重新登记。

### 设置页顶部新增「开机自启」指引

没开启时，设置页最上面会出现状态 + 完整步骤（不是只丢一句"去设置里看看"）：

1. 苹果菜单  → 系统设置
2. 左侧「通用」
3. 右侧「登录项与扩展」（macOS 14/15 叫「登录项」）
4. 「登录时打开」里找到 JLU Gate，打开开关
5. 列表里没有 → 点「＋」→ 应用程序 → JLU Gate → 打开
6. 提示「需要批准」→ 点允许，输密码或按指纹
7. 回到这里显示「✅ 已开启」就成功
8. ⚠️ App 必须在「应用程序」文件夹里，放 SD 卡/下载目录系统不会登记

主面板也会有一行提示：「🔁 开机自启还没打开」，点右边「去设置里打开」直接跳过去。

## 底栏文字首次打开偏小

底栏按钮用了自适应宽度 + 自动缩字，第一次弹出面板时容器宽度还在估算，文字会先缩一圈，
点一下才恢复。现在按钮改成固定宽度，第一次打开就是正常大小。

## 安装 / 升级

- macOS 26+：`JLU-Gate-v1.3.2.zip` / `.dmg`
- macOS 14/15：`JLU-Gate-v1.3.2-Compat.zip`
- 1.0.1 以后可在面板上点「更新」自动升级。
