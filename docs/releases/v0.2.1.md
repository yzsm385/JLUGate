# JLU Gate 0.2.1

> 这一版主要做两件事：把你担心的那些隐私漏洞逐条堵上；还有——人不在校园网时，别再自己满世界找入口，我直接把 WebVPN 递到你手边。

## 一、隐私加固（你那句"漏洞太多"，我一条条都查了）

| 之前 | 现在 |
|---|---|
| `config.json` 权限 **0644**（同机其他用户可读），里面有账号/学号 | **0600**，目录 **0700**；写入走临时文件，没有 0644 的窗口期 |
| `agent.log` 0644，且带完整账号、MAC、主机名、登录报文十六进制 | 0600；账号 `stu***`、MAC `02:00:00:**:**:*`、主机名 `tes***`；**报文默认不落盘** |
| 诊断导出里有完整账号与登记 MAC | 全部脱敏：账号/学号/登记 MAC |
| 复制密码后一直留在剪贴板 | **60 秒自动清空**（若期间你没复制别的东西） |
| 报文十六进制永远打印 | 只有 `verboseAuthLogging=true`（默认关）才打印，且账号已抹掉 |

凭据这块一直没变：走 Keychain（正式签名版）或 0600 文件（没签名的开发版）；密码不写日志、也不上屏。

## 二、人不在校园网？入口直接递给你

以前只会在结论里冷冰冰甩一句"用 WebVPN 再访问"，等于把活儿又推回给你了。现在只要判断你不在校园网，主面板上就会自己冒出一张卡：

- **打开 WebVPN**（一键开 `vpn.jlu.edu.cn`，并**自动把账号复制好**）
- **复制密码**（60 秒自清）
- 步骤写清楚：师生普通登录 → 统一身份认证 → 粘贴 → 输密码 → 返回点「重测」
- 判定依据：引擎报"不在校园网"，或体检发现仅校内系统全不通（邮箱不算）

## 三、顺带说两句

- 「站点合集」（0.2.0 起就有）：13 个常用的吉大站点，按学习/办事/邮箱/校园网/资讯分了类，能搜、也能一键复制账号；
- 「我的学院」：填学号 + 选一次学院，之后按学号前缀自动认出（不编造官方代码表，学号只存本机）。
