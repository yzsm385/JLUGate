# JLU Gate 0.3.10

> 拔网线后点「重试」不再闪退；开机自动连接更快。

## 闪退

诊断日志里能看到：拔掉网线后 `path interfacesChanged(current: [])`，物理网口列表变空。
此时点重试，程序仍会去建通道/做探针，在"没有任何物理口"的瞬间容易触发底层异常。

现在：

- `connect()` 先看物理网口；**一个都没有就直接给 `adapterUnplugged`**，不启动引擎；
- `retry()` 先记一行面包屑（接口数 / 当前状态），下次出问题能直接对账；
- 诊断导出文件新增 **「崩溃日志（最后 40 行）」**，闪退时只需发这一个文件。

## 开机自动连接更快

| | 0.3.9 | 0.3.10 |
|---|---|---|
| 第 1 次 | 4 秒 | **1.5 秒** |
| 重试间隔 | 5 秒 | **2 秒** |

连上或已有连接在跑就立刻停止。
