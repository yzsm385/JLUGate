# JLU Gate 1.4.2

> 1.4.1 的保活修复继续保留；这一版主要把「网络体检」里重复的模块合并、
> 把延迟/Ping 改成自动测，并让人机验证的名称和结论分列左右。

## 体检页合并

- **出口 IP**：把原来的「出口 IP / Cloudflare / 出口 IP 纯净度 / 多源归属 / BiliBili」
  合成一张卡。IP、国家/机房、归属运营商、ASN、IP 类型、备注和唯一一段说明
  都在同一张卡里，不再各写一遍。
- **DNS**：DNS 泄漏结果和「DNS 出口 vs IP 出口」的国家对照合并成一段说明，
  删掉重复的对照行。
- **认证通道 + Ping**：合并成一张「网络诊断 / 延迟」卡。两项都随体检**自动测**，
  不再放「测延迟」「开始 Ping」按钮；只保留一段说明和结果。
- **人机验证**：站点名（Google reCAPTCHA / Cloudflare…）靠左，
  「🟢 畅通可用 / 🔴 连不上」靠右，中间留空；不再把整串文字一起右对齐。

## 诊断

- 诊断文件头部带版本 / build / 正式或便携 / 兼容版 / macOS 版本 / 架构；
- 连接段带链路偏好、通道、保活间隔、容忍次数、上次成功登录；
- 保活逐包记录 `round / seq / session / mirror / size`，应答记录长度与 mirror；
- 日志尾部从 120 行扩到 400 行，在线巡检段带最后保活遥测与强制重登时间。

## 保活（延续 1.4.1）

B 保活子类型从 `05/06` 起、272 字节应答更新 mirror、请求/应答共用自增序号
（272 字节应答也占号）；JLU.WIFI 不再用「多久没收到保活」判断掉线。

## 安装 / 升级

- macOS 26+：`JLU-Gate-v1.4.2.zip` / `.dmg`
- macOS 14/15：`JLU-Gate-v1.4.2-Compat.zip`
- 1.0.1 以后可在面板上点「更新」自动升级。
