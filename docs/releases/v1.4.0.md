# JLU Gate 1.4.0

> 无线（JLU.WIFI）重做：**后台静默登录，不弹网页**；被挤下线会自己抢回来并告诉你。

## 之前为什么"完全连不上"

1. **门户入口找错了**：代码在拿不到重定向地址时，会去试 `http://<本机IP>/`。
   你的机器是 `10.66.51.154`，那个地址根本没有登录页，浏览器打开当然是一片空白。
   真正的登录页是 `http://net.jlu.edu.cn/`（Dr.COM 的网页登录页）。
2. **只会弹网页**：以前所有网页认证都靠"打开浏览器让用户自己登"，面板里点「我已完成登录」
   才继续。你输入了账号密码，但 App 不知道，也没法确认。

## 这一版

### 1. 后台静默登录（不弹网页）

新增 `EportalClient`：直接 POST 门户登录接口，两种都支持——

- 新版 EPortal：`https://<AC>:802/eportal/portal/login`（账号写成 `,0,<账号>`）；
- 老版 Dr.COM：`http://<host>:801/eportal/?c=ACSetting&a=Login`（`DDDDD` / `upass`）。

登录成功后立刻用 204 探针确认；只有接口明确"不支持静默登录"时才退回浏览器。
账号密码只在内存里用一次，不落盘、不写日志。

### 2. 门户入口优先找学校的

`net.jlu.edu.cn` → 网关 → 本机 IP，并且会**验证页面真的是登录页**
（含 Dr.COM / eportal / 表单特征），不再把"随便一个 200 的地址"当门户。

### 3. 被挤下线会告诉你

JLU.WIFI 同时最多 3 台设备，新设备一进就把最早的踢掉。检测到掉线时：

- 自动在后台重新登录（不用你动手）；
- 面板上写一句「📶 你被新设备挤下线了……我正在后台悄悄帮你重新登录」。

## 已知限制

静默登录依赖学校门户接口。如果哪天门户改版、接口返回"没有配置接入服务器"，
App 会自动退回"打开浏览器登录"的老办法，不会卡死。

## 安装 / 升级

- macOS 26+：`JLU-Gate-v1.4.0.zip` / `.dmg`
- macOS 14/15：`JLU-Gate-v1.4.0-Compat.zip`
- 1.0.1 以后可在面板上点「更新」自动升级。
