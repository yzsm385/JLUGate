# JLU Gate 1.4.4

> 出口 IP 分成「代理出口」和「国内出口」两条；规则模式下国内域名走直连，
> 会单独显示中国国旗。国旗去重：同一个国家只留一个旗。

## 出口 IP

- 体检除了默认路由（代理后）的出口，还会用国内域名回显服务测一条**国内出口**。
- 规则模式下代理出口和国内出口不同：例如代理出口 🇺🇸、国内出口 🇨🇳，
  两条分别显示；全局模式下两个 IP 相同，国内出口行自动隐藏，只留一个国旗。
- 纯净度卡片里原来重复的国旗已去掉；同一个出口只集中显示一个旗。

## 上一版延续

- 认证通道 / Ping 的延迟行已并入出口 IP 卡片（不再单独有「网络诊断」模块）。
- GPA 面板记住上次选的专业，下次直接预选。
- GPA 网页：四史默认、外语只列计入推免的大学英语、推免线卡片移出课程列表。

## 安装 / 升级

- macOS 26+：`JLU-Gate-v1.4.4.zip` / `.dmg`
- macOS 14/15：`JLU-Gate-v1.4.4-Compat.zip`
- 1.0.1 以后可在面板上点「更新」自动升级。
