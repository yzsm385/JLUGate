# JLU Gate 0.3.9

> 启动后自动连接：等几秒、失败重试，最多 5 次。连接协议路径未动（冻结检查通过）。

## 为什么之前重启后要手动点

以前只在启动后 **0.8 秒**试一次。开机时网卡/IP/路由往往还没就绪，这一次必然失败，
之后不会再试——所以每次都得你手动点。

现在：

- 第 1 次：启动后 **4 秒**；
- 之后每 **5 秒**一次，最多 **5 次**；
- 一旦连上（或已有连接在进行）就停；
- 5 次都没成功才停手，并写日志。

## 关于"没放进 /Applications 也会自己起来"

你的诊断里有一行：

```
磁盘上还有另一份 JLU Gate：/Applications/JLU Gate.app build=202611031650（比当前旧）
```

那份旧版很可能就是被系统记住的登录项。macOS 的开机自启按**当时注册的那份 App 路径**恢复，
和现在这份放在 SD 卡/下载目录的没有关系。

建议：删掉 `/Applications/JLU Gate.app`（旧版），再把新版拖进去，统一成一份；
然后在 系统设置 → 通用 → 登录项与扩展 里确认只有一份 JLU Gate。
