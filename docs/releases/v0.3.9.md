# JLU Gate 0.3.9

> 这版主要解决一件烦心事：重启之后总得手动点一下才肯连。现在它会自己等、自己重试，最多试 5 次。连接协议路径未动（冻结检查通过）。

## 为什么以前重启后总得手动点

以前它只在启动后 **0.8 秒**试一次。可刚开机那会儿，网卡、IP、路由多半还没缓过神来，这唯一的一次自然连不上——
连不上之后它又不再试了，所以每次都得你亲自点一下。

现在的做法耐心多了：

- 第 1 次：启动后 **4 秒**；
- 之后每 **5 秒**一次，最多 **5 次**；
- 一旦连上（或者已经有连接在跑）就立刻停手；
- 5 次都没成功才罢休，并写一行日志。

## 关于"没放进 /Applications 也会自己起来"

你的诊断里有一行：

```
磁盘上还有另一份 JLU Gate：/Applications/JLU Gate.app build=202611031650（比当前旧）
```

那份旧版，多半就是被系统记住的登录项。macOS 的开机自启认的是**当初注册时的那份 App 路径**，
跟你现在这份放在 SD 卡、下载目录里的，其实没什么关系。

建议：删掉 `/Applications/JLU Gate.app`（旧版），再把新版拖进去，统一成一份；
然后在 系统设置 → 通用 → 登录项与扩展 里确认只有一份 JLU Gate。
