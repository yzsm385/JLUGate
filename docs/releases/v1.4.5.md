# JLU Gate 1.4.5

> 1.4.4 的国内出口行在“不同国家”时会同时出现左侧旗和右侧带旗的国家标签，
> 同一行出现两个 🇨🇳。这一版把右侧改成纯国家代码，只保留左侧一个旗。

## 修复

- 出口 IP：代理出口与国内出口国家不同时，国内出口行只显示一个国旗 + 国家代码；
  相同时仍只集中显示代理出口那一个旗。
- 其余内容同 1.4.4：国内域名单独测出口、GPA 记住专业、
  网络诊断并入出口 IP 延迟行、GPA 网页四史/外语/推免线调整。

## 安装 / 升级

- macOS 26+：`JLU-Gate-v1.4.5.zip` / `.dmg`
- macOS 14/15：`JLU-Gate-v1.4.5-Compat.zip`
- 1.0.1 以后可在面板上点「更新」自动升级。
