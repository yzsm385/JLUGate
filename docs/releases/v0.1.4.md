# JLU Gate 0.1.4

> 只改文案与判定依据：**邮箱（mails.jlu.edu.cn）校内外都能开**，不再被当成“仅校内”。

## 之前哪里自相矛盾

体检页把「教务 / 通知 / 邮箱」放在一个小标题下写“只在校园网内可访问”，
但邮箱在校外也是通的——你说得对，这是文案和事实打架。

## 现在

- 小标题改成：**校内系统（教务/通知仅校内；邮箱校内外都能开）**
- 每个站点后面直接标访问范围：
  - `iedu.jlu.edu.cn`、`oa.jlu.edu.cn` → **仅校内网**
  - `mails.jlu.edu.cn` → **校内外都能开**
- 判定“是不是不在校园网”时，只用**仅校内**的系统做证据；邮箱永远不算：
  公网通 + 教务/通知不通 → 才提示 WebVPN，并且结论里会明确写“邮箱校内外都能开，不算证据”。

## 验证

新增两条测试：
- `accessNotes`：邮箱=校内外都能开、教务=仅校内、公网站点无标注；
- `campusUnreachable`：结论文案不得出现“邮箱全不通”，必须写明邮箱不算证据。

全量 168 tests 通过、三个离线自测通过、隐私扫描通过。
