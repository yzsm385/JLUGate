# JLU Gate 0.1.4

> 这版没动代码逻辑，只改文案和判定依据：**邮箱（mails.jlu.edu.cn）在校内校外都开得了**，不再被误当成"仅校内"。

## 之前哪里自相矛盾了

体检页把「教务 / 通知 / 邮箱」放在一个小标题下，统一写着"只在校园网内可访问"——
可邮箱在校外明明也通。你说得对，这就是文案跟事实打了一架。

## 现在怎么处理

- 小标题改成了：**校内系统（教务/通知仅校内；邮箱校内外都能开）**；
- 每个站点后面直接标上访问范围，一目了然：
  - `iedu.jlu.edu.cn`、`oa.jlu.edu.cn` → **仅校内网**
  - `mails.jlu.edu.cn` → **校内外都能开**
- 判断"我是不是不在校园网"的时候，只用**仅校内**的系统当证据，邮箱永远不算数：
  也就是说，得是"公网通 + 教务/通知不通"才会提示你走 WebVPN，而且结论里会白纸黑字写明"邮箱校内外都能开，不算证据"。

## 验收

这次加了两条测试盯着这件事：
- `accessNotes`：邮箱=校内外都能开、教务=仅校内、公网站点不带标注；
- `campusUnreachable`：结论文案不许出现"邮箱全不通"，必须写明邮箱不算证据。

全量 168 tests 通过、三个离线自测通过、隐私扫描通过。
