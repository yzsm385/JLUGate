# JLU Gate 0.3.16

> 修一个让人以为"信息丢了"的按钮。

## 之前

被动观测到"你本来就在线"（浏览器/别处认证过）时，面板总是显示
**「填写账号密码（断线后自动重连）」**，即使你早就填好、密码也验证过。
看起来就像信息丢了，其实配置一直都在。

## 现在

- 新增判断 `hasStoredCredentials`：账号非空 + 本机有密码 + 曾成功登录过；
- 有凭据 → 显示正常的 **「下线 / 立即连接」**；
- 只有**真正缺凭据**时，才出现「填写账号密码」按钮。

## 附：重启后的判断依据

启动日志里会有一行：

```
启动决策：账号=true 密码=true（已验证保存=true） 静态参数完整=true 需要向导=false 自动连接=true
```

以后再遇到"是不是丢了"，看这一行就行，不用猜。
