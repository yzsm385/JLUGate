# JLU Gate 0.3.16

> 这版就修一个小事：面板上有个按钮总在错误的时机出现，让人以为账号信息丢了。

## 之前是怎样的

有时候你其实在别处（浏览器之类的）已经认证过、本来就在线，面板却还是显示
**「填写账号密码（断线后自动重连）」**，哪怕账号早填好、密码也验证过了。
看起来像信息丢了，其实配置一直好好待在那儿。

## 现在怎么判断

- 新增一个判断 `hasStoredCredentials`：账号非空 + 本机有密码 + 曾成功登录过；
- 凭据齐全 → 显示正常的 **「下线 / 立即连接」**；
- 只有**真的缺凭据**时，才把「填写账号密码」按钮亮出来。

## 顺带说一句：重启后怎么自查

启动日志里会有这么一行：

```
启动决策：账号=true 密码=true（已验证保存=true） 静态参数完整=true 需要向导=false 自动连接=true
```

以后再拿不准"是不是丢了"，看这一行就行，不用瞎猜。

193 tests / 三个离线自测 / 隐私扫描 / 连接冻结检查 全绿。
