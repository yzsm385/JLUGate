# JLU Gate 0.3.7

> 界面按你的要求重整；**连接路径未动**（CI 冻结检查通过）。

## 主界面

- **不再有「状态」面板**：连接结果、错误原因、最近事件、已在线时长都搬到主界面；
- **已在线时长实时走**：以登录时间为起点每秒刷新（以前只读引擎上报值，心跳一停就冻住）；
- 主面板底部只保留：设置 / 站点 / 详情 / 体检 / 诊断 / 退出。

## 菜单栏图标

- 左键 = 打开面板；
- **右键 = 菜单**：立即连接/断开、刷新状态、网络体检、设置…、退出。

## 体检

- **点进去就自动检测**；按钮改成「重新检测」，只当重试用。

## 详情页

- 删掉末尾单独的「这些字段是什么意思」整块；
- 含义直接挂在对应卡片底部：网口/MAC/IPv4、掩码/网关/DNS/路由、VPN/TUN、
  测速（Mbps vs MB/s）、Ping、代理模式。

## 站点合集

- **校园广告/门户入口搬进「站点合集」**，主面板不再单独占一行。

## 诊断

- 「导出 / 参数卡 / 诊断」三个按钮合并为**「诊断与开发」**一个面板，
  里面写清每项用途；导出内容均已脱敏。

## 校园网判断

- 不再用"体检里校内网站打不开"推断你不在校园网；
  只有引擎明确判定 `notCampusNetwork` 才提示，避免插着网线却被说"不在校园网"。
