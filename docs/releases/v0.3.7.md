# JLU Gate 0.3.7

> 这版按你的要求把界面收拾了一遍；**连接那条路径一点没动**（CI 冻结检查通过）。

## 主界面

- **「状态」面板没了**：连接结果、错误原因、最近发生的事、已在线多久，全都搬上主界面；
- **已在线时长现在会自己走**：以登录时间为起点每秒刷新（以前只读引擎上报的值，心跳一停就冻在那里）；
- 主面板底部只留：设置 / 站点 / 详情 / 体检 / 诊断 / 退出。

## 菜单栏图标

- 左键 = 打开面板；
- **右键 = 菜单**：立即连接/断开、刷新状态、网络体检、设置…、退出。

## 体检

- **点进去就自动开检**；按钮改叫「重新检测」，留着只当重试用。

## 详情页

- 末尾那块单独的「这些字段是什么意思」整段删了；
- 含义直接挂在对应卡片底部：网口/MAC/IPv4、掩码/网关/DNS/路由、VPN/TUN、
  测速（Mbps vs MB/s）、Ping、代理模式。

## 站点合集

- **校园广告、门户入口都搬进了「站点合集」**，主面板不再单独占一行。

## 诊断

- 「导出 / 参数卡 / 诊断」三个按钮合成**「诊断与开发」**一个面板，
  每项干什么用都写清楚了；导出的内容都已经脱敏。

## 校园网判断

- 不再拿"体检里校内网站打不开"来推断你不在校园网了；
  只有引擎明确判定 `notCampusNetwork` 才提示，免得你明明插着网线却被说"不在校园网"。
