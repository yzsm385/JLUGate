# JLU Gate 0.3.15

> 这版我做了两件事：把平时没人留意的小开销降下来，再让"重启后又要填账号密码"这个小烦人的问题能自己恢复、也说得清原因。

## 省下来的开销

后台一直在悄悄跑的几件事，现在改得更"知道分寸"了：

| 位置 | 之前 | 现在 |
|---|---|---|
| 菜单栏图标 | 每 600ms 重建一次 NSImage | **只在图标变化时**重建，轮询 1s |
| 主面板计时 | 每秒刷新（关着面板也在跑） | 只在**在线且面板可见**时刷新 |

## 重启后弹"填写账号密码"

如果你重启后又看到这个弹窗，先别急着重填——这次启动会留一行决策依据，告诉你到底卡在哪：

```
启动决策：账号=true 密码=true（已验证保存=true） 静态参数完整=true 需要向导=false 自动连接=true
```

万一重启后真的又弹了向导，看这行就知道缺哪一项。另外我也加了点自动恢复：

- 配置里账号是空的、但本机凭据库只存过一个账号 → **自动把账号填回来**并落盘；
- 静态参数丢了的话，向导里点「用系统当前读数填入」能一键补回。

> 另外提醒一句：如果你开机启动的是 `/Applications` 里那份**旧版**（build `202611031650`），
> 它可能用旧逻辑把配置覆盖掉。建议删掉它，只留一份 App。
