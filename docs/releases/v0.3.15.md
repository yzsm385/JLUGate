# JLU Gate 0.3.15

> 降低常驻开销；并给"重启后又要填账号密码"加上自恢复与诊断日志。

## 性能

| 位置 | 之前 | 现在 |
|---|---|---|
| 菜单栏图标 | 每 600ms 重建一次 NSImage | **只在图标变化时**重建，轮询 1s |
| 主面板计时 | 每秒刷新（关着面板也在跑） | 只在**在线且面板可见**时刷新 |

## 重启后弹"填写账号密码"

现在启动会打一行决策依据：

```
启动决策：账号=true 密码=true（已验证保存=true） 静态参数完整=true 需要向导=false 自动连接=true
```

如果重启后又弹向导，这行会明确告诉你缺哪一项。另外新增自动恢复：

- 配置里的账号为空、但本机凭据库只存过一个账号 → **自动把账号填回来**并落盘；
- 静态参数丢失时，向导里点「用系统当前读数填入」可一键恢复。

> 注意：如果开机启动的是 `/Applications` 里那份**旧版**（build `202611031650`），
> 它可能用旧逻辑覆盖配置。建议删掉它，只保留一份 App。
