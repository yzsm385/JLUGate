# JLU Gate 1.4.3

> GPA 记住选过的专业；体检移除独立的「网络诊断」模块，延迟并入出口 IP 卡片。
> GPA 网页的四史/外语/推免线调整同版本上线。

## GPA
- 选过一次专业后记在本机；下次打开 GPA 面板直接预选，不用每次再选。
- 学院或年级变了、原专业在新方案里不存在时，才会回到未选状态。

## 体检
- 删除独立的「网络诊断」卡片（原来那一段 emoji 长句和独立模块）。
- 认证通道、网关/公网延迟改成「名称靠左、数值靠右」的行，并入「出口 IP」卡片，
  和人机验证同一个格式；不再显示带 emoji 的 PingSummary 长句。
- DNS 卡片保留自己的解析结果和国家对照，不再和诊断段重复。

## GPA 网页（同版本线上）
- 四史：2025 级及以前默认《中华人民共和国史》，不再显示 4 选 1；2026 起才显示选择器。
- 外语：默认英语；只列计入推免的大学英语 Ⅱ/Ⅲ/Ⅳ（2026 起仅 Ⅲ/Ⅳ），
  BⅠ、预备级、写作/翻译/文学/概况/学术英语等拓展课隐藏；同课程分级重复行合并。
- 学院推免口径 / 历年线移到计算器课程列表外，放在警告与搜索框之间的独立卡片。

## 安装 / 升级

- macOS 26+：`JLU-Gate-v1.4.3.zip` / `.dmg`
- macOS 14/15：`JLU-Gate-v1.4.3-Compat.zip`
- 1.0.1 以后可在面板上点「更新」自动升级。
