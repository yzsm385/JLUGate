# JLU Gate 1.1.2

> 只改了一处：地址输入框里的数字居中，**输入框的位置保持原样**。

1.1.1 里为了放下英文长标签，把标签列从 64 加宽到 92，结果「子网掩码 / 登记 MAC」那几行的
输入框整体右移了——这不是你要的。这一版：

- 标签列宽度改回 64（长标签在列内换行，不再把输入框推走）；
- 输入框里的数字仍然默认居中；
- 居中的那层显示被限制成和输入框同宽，不会再撑宽整行。

其余与 1.1.1 相同（三语言、语言切换、英文排版修复、圆角加大）。

## 安装 / 升级

- macOS 26+：`JLU-Gate-v1.1.2.zip` / `.dmg`
- macOS 14/15：`JLU-Gate-v1.1.2-Compat.zip`
- 1.0.1 以后可在面板上点「更新」自动升级。
