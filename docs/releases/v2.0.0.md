# JLU Gate 2.0.0

> 全新品牌视觉与 Apple macOS App Icon HIG 规范图标正式上线，同步完善打包文档与深浅色展示体验。

## 这一版带来了什么

### 1. 全新 App 图标（浅色 / 深色双模式适配）
- **品牌元素融合**：以正宗吉大蓝液态玻璃（Liquid Glass）为底，融合**吉大校徽飞鹅**、**校园大门拱廊**、**Apple SF Symbols 风格直线切口 Wi-Fi 信号弧**与**拟物金属 RJ45 有线网口**——一眼传达「有线网口 + JLU.PC + JLU.WIFI 三合一闸口」。
- **严格遵循 Apple macOS App Icon HIG**：`1024×1024` 真透明画布、`824×824` Apple 连续圆角超椭圆与 `100px` 透明安全边距、原生软阴影与内缘折射高光，确保在访达、程序坞（Dock）与启动台中与系统应用等大对齐。
- **双模式与全分辨率资源**：通过 Xcode `actool` 编译 `Assets.car` + `AppIcon.icns`，完整覆盖 `16×16` 至 `512×512@2x`（`1024px`），并配套浅色 / 深色两套品牌源图（`README.md` 顶部自动随 GitHub 深浅色主题切换）。
- **零依赖构建脚本**：新增 `scripts/build-app-icon.swift`（原生 CoreGraphics + `actool`），随时可复现全部图标资源。

### 2. 打包与使用说明修正
- 同步接入新版包（macOS 26+ Liquid Glass）与旧版适配包（macOS 14/15 Compat）的图标资源及 `Info.plist`（`CFBundleIconFile` / `CFBundleIconName`）。
- 修正便携分发包内 `README.txt` 中的三处陈旧信息：版本号改为动态同步、账号密码说明更正为**统一身份认证密码**（避免与吉大邮箱独立密码 / 校园卡 6 位密码混淆）、卸载脚本名称与实际文件 `Uninstall JLU Gate.command` 保持一致。

## 验证
- `make ci` 全部通过（单元测试 + 模拟网关自测 + 模拟门户自测 + 隐私扫描 + 连接冻结守卫）
- 新版包（`JLU Gate 2.0.0.zip` / `.dmg`）与旧版适配包（`JLU Gate 2.0.0 (Compat).zip`）均通过 `codesign --verify --strict` 与 `vtool` 部署目标校验

## 升级建议
- 从 1.0.1 – 1.5.0 升级：直接在菜单栏面板点「更新」一键升级，或下载对应版本 ZIP 覆盖 `/Applications` 即可，配置与凭据完整保留。
- 本版本不改动认证核心路径，稳定沿用 1.5.0 的分层探针与校内优先 DNS 策略。
