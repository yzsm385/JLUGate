# JLU Gate 0.2.9

> 把"自动帮你填"这件事找回来了，顺手修了 MAC 框每敲一个字就跳一格的毛病。

## 自动预填（IP / 掩码 / 网关 / MAC）

| 场景 | 现在 |
|---|---|
| 进入向导「网络参数」 | 自动读一次系统当前值 |
| 网卡是 DHCP / 读不到配置方式 | **仍然带出系统当前读数**，用橙色提示"这是自动分配的，别当静态值"（以前直接不填） |
| IP 填完、掩码空着 | 自动补 `255·255·255·0` |
| IP 填完、网关空着 | 按同网段补 `x.x.x.254`（提示可改） |
| 登记 MAC | 自动填当前网卡（优先正在用/有线）的**出厂 MAC**——它与地址是否 DHCP 无关 |

设置页的「读系统值」也照着这套来：先把网卡刷新一遍再读，免得 MAC 读出来是空的。

## MAC 输入框一格只能输一个字符

原因在输入回调里：它读的是 `field.stringValue`。可你正在编辑的时候，
这个值可能还是旧的——拿它去判断长度就会**误以为已经填满**，
于是每敲一个字符就跳到下一格，有时候还会把字符吞掉。

现在改成读**字段编辑器**（`NSTextView`）里的真实内容，过滤和截断都基于它；
只有刚好输满两个十六进制字符、而且光标停在末尾时，才跳到下一格。
