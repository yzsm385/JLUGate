# JLU Gate 0.2.9

> 恢复"自动帮你填"，并修 MAC 输入框一字符就跳格。

## 自动预填（IP / 掩码 / 网关 / MAC）

| 场景 | 现在 |
|---|---|
| 进入向导「网络参数」 | 自动读一次系统当前值 |
| 网卡是 DHCP / 读不到配置方式 | **仍然带出系统当前读数**，用橙色提示"这是自动分配的，别当静态值"（以前直接不填） |
| IP 填完、掩码空着 | 自动补 `255·255·255·0` |
| IP 填完、网关空着 | 按同网段补 `x.x.x.254`（提示可改） |
| 登记 MAC | 自动填当前网卡（优先正在用/有线）的**出厂 MAC**——它与地址是否 DHCP 无关 |

设置页「读系统值」同样：先刷新网卡再读，避免 MAC 为空。

## MAC 输入框一格只能输一个字符

根因：输入回调里读的是 `field.stringValue`。正在编辑时它可能还是旧值，
拿它做长度判断就会**误判已满**，于是每敲一个字符就跳下一格（甚至吞掉字符）。

现在改为读**字段编辑器**（`NSTextView`）里的真实内容，过滤/截断都基于它；
只有刚好输满两个十六进制字符、且光标在末尾时才跳到下一格。
