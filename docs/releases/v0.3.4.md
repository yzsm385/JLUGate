# JLU Gate 0.3.4

> 撤回我在 0.2.5 引入的「有线没地址就报错」，选网卡回到 **0.2.2 的行为**。

## 为什么又连不上

0.2.5 我加了这条规则：自动模式下只要有线网卡存在，就必须用有线；有线没有 IPv4 就直接报错。
本意是防止"程序自己跑到 Wi‑Fi"，但副作用是——**有线地址还没配好时，连接必然失败**。
0.2.2 没有这条规则，所以那时候能连。

现在 `chooseInterface` 与 v0.2.2 完全相同：
- 评分选口（MAC 命中 > 有线 > 有地址）；
- 不再因为"有线没地址"拒绝连接；
- 实际选了哪块口写进日志，方便对账。

保留的只有展示层：网口列表排序、JLU.WIFI 不会被有线抢走。
