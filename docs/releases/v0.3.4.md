# JLU Gate 0.3.4

> 这一版我把 0.2.5 里自作主张的一条规矩撤了——选网卡回到 **0.2.2 那会儿的样子**。

## 为什么又连不上了

0.2.5 我加了这么一条：自动模式下只要有线网卡在，就必须走有线；有线没 IPv4 地址就直接报错。本意是不让程序自作主张跑去蹭 Wi‑Fi，可副作用是——**有线地址还没配好的当口，连接注定失败**。0.2.2 那时没这条规矩，所以能连上。

现在 `chooseInterface` 跟 v0.2.2 完全一样了：
- 评分选口（MAC 命中 > 有线 > 有地址）；
- 不再因为"有线没地址"就把你拒之门外；
- 到底选了哪块口会写进日志，方便你对账。

留下来的只有展示层那点东西：网口列表排序、JLU.WIFI 不会被有线抢走。
