# JLU Gate 0.3.3

> 这版处理了件小事、但挺招人烦的事：你用中间点填地址，它不再冲你喊「格式错误」，落盘时还会悄悄帮你换成标准写法。

- 解析：`·`、`．`、`．`、`：`、`-` 它都认得（IPv4 / MAC 都行）；
- 保存时顺手规范化：界面上你看到的是 `255·255·255·0`，配置文件里存的是 `255.255.255.0`；
- 校验走的是同一套解析，所以"你按格子里填的"就一定是"被接受的值"，
  不会再闹出"分隔符是你自己敲的、结果反过来怪你填错"这种别扭；
- 新增了测试：中间点参数能通过校验；不同网段照样会报错。

189 tests / 三个离线自测 / 隐私扫描通过。
