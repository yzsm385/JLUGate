# JLU Gate 0.1.3

> 0.1.2 把登录修好了；这版接着修一个更尴尬的——**一点设置就闪退**。

## 闪退不是玄学，原因写得明明白白

崩溃日志里写得很清楚：

```
NSGenericException: The window has been marked as needing another Layout Window pass,
but it has already had more Layout Window passes than there are views in the window.
<_NSPopoverWindow>
```

说穿了是这样：我新写的那个分段地址框，在 `layout()` 里顺手改了自己的 `frame.size.width`——
这一改，窗口马上又得重新排一次版，AppKit 排来排去超过视图数量就抛异常，进程直接被杀。
所以你看到的现象是"一进设置就闪退"，但其实网络会话在服务端还活着，网并没断。

改法很简单：`layout()` 里**老老实实只摆子视图，绝不碰自己的 frame**；宽度交给 `intrinsicContentSize` 去算。

## 顺手调的

- 把分段格子加宽了点（IP 每段 52pt、MAC 34pt），三位数字不再挤成一团；
- 键盘操作跟以前一样：点任意段就能改、Enter 跳下一段、←/→ 跨段、⌫ 退段。

## 验收

- `PANEL=settings` 和向导的"网络参数"那两步都能稳稳打开了，进程活得好好的，崩溃日志也没再往上涨；
- 全量测试 167 通过、三个离线自测通过、隐私扫描通过。
