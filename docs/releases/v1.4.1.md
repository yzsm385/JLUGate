# JLU Gate 1.4.1

> 修好 1.4.0 的"静默登录其实没生效"：JLU.WIFI 现在真的会在后台自动登录，
> 不再把你丢进 Safari、也不用再对着系统弹窗干瞪眼。

## 1.4.0 为什么还是弹网页

1.4.0 里 `EportalClient` 先请求 `http://net.jlu.edu.cn:801/eportal/?c=ACSetting&a=Login`，
读到 302 的 `Location` 后，把登录地址改写成了 **`https://10.100.61.7:802/...`**。
学校的 TLS 证书是 `*.jlu.edu.cn`，按 IP 连必然校验失败，于是静默登录每次都返回
"不支持" → 回退到浏览器。你看到的就是"网页能打开，但还是要自己输账号密码"。

顺带还有一个观察不到的问题：门户链路内部的日志（静默登录失败原因、被挤下线…）
没有接进协调器，UI 和 `agent.log` 里都看不到，所以只能靠猜。

## 这一版

### 1. 按吉大实际接口登录：`/drcom/login`

吉大现在的 Dr.COM 门户登录走的是：

```
GET https://net.jlu.edu.cn/drcom/login?callback=dr1003
    &DDDDD=<账号>&upass=<密码>&0MKKey=123456&...
```

这一版会直接请求它（带完整参数：`R1/R2/R3/R6/para/v6ip/terminal_type/lang`），
`result=1` 即成功，`result=0` 会按 `msg` / `msga` 翻译成人话（密码错、余额不足、
停机、系统繁忙、IP 不在范围…）。原来的 EPortal 4.x 和老版 ACSetting 仍保留，
作为其它门户/改版后的兜底。

### 2. 不再往 IP 上打 HTTPS

`resolveEportalBase` 现在只借 801 的 302 确认 EPortal 在线，真正请求始终用
`net.jlu.edu.cn` 域名（证书匹配）。同时，入口如果是网关 IP，会先试学校域名，
回环 / 本机测试地址则不会去打扰真实门户。

### 3. 重启后也能真正"自动登录"

以前网页认证链路从不发 Dr.Com 的会话遥测，所以保存的密码永远停在"未验证"；
下次启动 `connect()` 看到"未验证"就会弹向导，让用户重新输一遍——所谓自动登录
其实只在同一次运行里有效。

这一版在 **204 探针确认在线之后**把凭据标成已验证（`portalAuthenticated`），
之后启动就能直接复用保存的密码。

### 4. 日志终于能看到了

`PortalEngine` 实现 `SessionTelemetryProviding`，把内部 `.note` 接进
`AuthCoordinator`。以后 `agent.log` 里能看到：

- `🔐 正在后台静默登录（不弹网页）…`
- `✅ 已经悄悄帮你登录好了…`
- `静默登录失败：…` / `门户接口不支持静默登录，改用浏览器`

### 5. 系统弹窗能关了

连 JLU.WIFI 时那个"加入 JLU.WIFI"的网页窗是 macOS 的「捕获门户助手」
（Captive Network Assistant），不是 App 弹的，也没有正常关闭按钮。这一版：

- 认证成功、204 探针通过后自动结束它；
- 网页认证面板 / 失败状态下新增「🧹 关掉系统登录弹窗」按钮，可手动结束。

它只是一个网页窗口，结束它不会断开 Wi-Fi，也不会影响已经建立的会话。

## 仍然要知道的

- 如果学校门户改版到接口不认，App 仍会退回"在浏览器里登录"，不会卡死；
  但 Safari 的登录页**无法**被第三方 App 预填（这是 Safari 的安全设计），
  所以那种情况下还是得手动输入。
- 密码只在内存里用于这一次 HTTPS 登录请求，不写日志、不落盘。

## 安装 / 升级

- macOS 26+：`JLU-Gate-v1.4.1.zip` / `.dmg`
- macOS 14/15：`JLU-Gate-v1.4.1-Compat.zip`
- 1.0.1 以后可在面板上点「更新」自动升级。

### 6. 有线反复断连：保活 B 的三个坑

诊断日志里 `保活 B 无应答` 越积越多、十几分钟后被门户拦下重新登录。根因都在
B 保活报文上，而且只有真网关的 **272 字节应答** 才会暴露：

1. **子类型错位**：抓包第一对 B 是 `05/06`，代码把 A/B 交替的 round 直接当 B 子类型，
   实际发成 `06/07`，网关不应答。
2. **mirror 没更新**：真网关回 272 字节，分类逻辑认出来了，但更新 mirror 时又调了
   只认 40 字节的解析器，异常被吞掉，mirror 永远是 0。
3. **序号漏加**：抓包里请求/应答共用一个自增序号（请求 01 → 应答 02 → 请求 03）。
   之前只对 40 字节应答加序号，272 字节应答后下一个请求又用了应答的序号，
   网关当成重复包丢掉。

这一版把三处都修了，并加了用 272 字节真形状应答的回归测试：
B 子类型必须是 `05/06/07/08`、272 字节应答必须更新 mirror、且必须占用序号。

另外，JLU.WIFI 是门户会话，不靠保活包续命；在线巡检不再用"多久没收到保活"
去判定无线掉线，只让 204 探针决定要不要重认证。

### 7. GPA / 保研集成重做

- 直接从登录邮箱前缀解析学院 + 年级（`zhangcyy5525` → 55 软件学院 / 2025 级），
  不再要求填学号；
- 专业在 App 里选一次，点「进入计算器」**直接打开对应年级的 plan.html /
  software.html**，不再先去网页首页选专业；
- 认不出学院时才展示手动选择；网页入口保留为兜底；
- `GPA01/GPA02` 直接显示成编号的文案缺失已修，并加了扫描所有 `Copy.t` key 的测试，
  缺任何一条三语文案都会让 CI 失败。

### 8. 界面整理

- 主面板不再显示本机 IP；完整的 IP / 掩码 / MAC / 网口移到「网络详情」顶部；
- 详情页的测延迟 / Ping / HTTP 下载残留删除；带宽随体检自动测；
- 设置页「界面语言」下的解释行删除；新生小贴士并入萌新指南；
  参数填完并成功连接后，萌新指南收到底部折叠；
- 主面板明细的标签和值统一 11pt、注解 10pt，去掉挤在状态卡里的 9pt 技术日志；
- 出口 IP 纯净度左栏加宽到 96pt；人机验证的短结论靠右显示。

### 9. 诊断信息更完整

- 头部带版本 / build / 正式或便携 / 兼容版 / macOS 版本 / 架构；
- 连接段带链路偏好、通道、保活间隔、容忍次数、上次成功登录；
- 保活日志逐包记录 `round / seq / session / mirror / size`，
  应答记录长度与 mirror；日志尾部从 120 行扩到 400 行；
- 在线巡检段带当前链路、最后保活遥测、上次强制重登时间。
