# JLU Gate 0.2.5

> 这一版收拾了三个真问题：**更新完配置莫名清空、一更新就“连不上”**、**自动选口老往无线上跑**、还有**设置页被撑得没法看**。一个个说。

## 1. 更新后账号/网关全丢（这就是“突然连不上”的真凶）

这事说起来有点绕，但根子不深：

- 旧 `config.json` 没带新增的字段 → 整份解码失败 → 程序没吱声，默默用上了默认配置 → 账号、静态 IP、网关、登记 MAC 一夜之间全没了，那当然连不上。
- 现在每个字段都“缺了就给个默认值”，旧的、新的配置都能正常读进来；
- 解码失败**不会再一声不吭**了：会留一份 `config.unreadable-<时间>.json`，并试着拉 `config.backup.json` 救一下；
- 而且每次保存前，都会先悄悄留一份 `config.backup.json`。

## 2. 自动选口：有线优先，别再“锁死在 Wi‑Fi”上

- 自动模式下，只要有线网卡在，就一定走有线；要是有线没拿到地址，它会明明白白报一句「接口 enX 没有 IPv4，请填静态参数或改用 DHCP」，而不是背着你偷偷改去无线；
- `link=auto` 时旧的无线锁定会被自动忽略（并写日志）；
- 网口列表按优先级排序：**正在用的 → 有线有地址 → 有线无地址 → 无线有地址 → 无线无地址 → 虚拟**。

## 3. 设置页别再撑爆，字段的含义直接写旁边

- 输入框和标签那一列收窄了，更新区也改成竖排换行，不再挤成一团；
- 那一大段笼统的"说明"也去掉了，改成把每个字段的含义直接写在它下面：
  IP＝学校分配给你的固定地址、掩码＝一般是 255.255.255.0、网关＝通常是 x.x.x.254、
  DNS＝10.10.10.10、登记 MAC＝学校登记的那块网卡。

## 顺带收拾的几处

- 站点合集页上重复的「返回」按钮，去掉了；
- 「我的学院」现在会显示「一共 N 个学院 / 匹配 N 个」，还能展开看全部——免得你以为吉大就 6 个学院。
