# JLU Gate 0.2.5

> 修三个真问题：**配置被清空导致"连不上"**、**自动选口跑去无线**、**设置页撑爆**。

## 1. 更新后账号/网关全丢（这是"突然连不上"的真凶）

- 旧 `config.json` 没有新增字段 → 整份解码失败 → 程序静默用默认配置
  → 账号、静态 IP、网关、登记 MAC 全部消失，自然连不上。
- 现在每个字段都"缺了就用默认值"，旧配置/新配置都能读；
- 解码失败**不再静默**：保留 `config.unreadable-<时间>.json`，并尝试 `config.backup.json`；
- 每次保存前自动留一份 `config.backup.json`。

## 2. 自动选口：有线优先，不再"锁到 Wi‑Fi"

- 自动模式下只要有线网卡在，就一定用有线；有线没地址就明确报
  「接口 enX 没有 IPv4，请填静态参数或改用 DHCP」，不偷偷改无线；
- `link=auto` 时旧的无线锁定会被自动忽略（并写日志）；
- 网口列表按优先级排序：**正在用的 → 有线有地址 → 有线无地址 → 无线有地址 → 无线无地址 → 虚拟**。

## 3. 设置页不再撑爆，字段含义内联

- 分段输入框与标签列收窄，更新区改成竖排换行；
- 去掉整段"说明"，把含义直接写在每个字段下面：
  IP＝学校分配的固定地址、掩码＝一般 255.255.255.0、网关＝通常 x.x.x.254、
  DNS＝10.10.10.10、登记 MAC＝学校登记的那块网卡。

## 其它

- 站点合集页去掉重复的「返回」；
- 「我的学院」显示「一共 N 个学院 / 匹配 N 个」并可展开全部，不再让人以为只有 6 个。
