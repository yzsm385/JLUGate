# JLU Gate 2.1.0

> 彻底修复一键更新下载误报停滞与失败无反馈问题，统一专属学院识别并自动复用校园网账号，同时加固发布流水线的版本与图标校验门禁。

## 这一版带来了什么

### 1. 一键更新下载与状态机重构
- **修复 1 秒误报「下载几乎停滞（Zero KB/s）」**：抽离独立停滞判定器 `DownloadStallDetector`，建连 / TLS 握手 / 302 重定向阶段给予 **25 秒首字节宽限**；收到首字节后改用 **12 秒连续滑动窗口平均速度** 判定停滞，不再因建连耗时或单秒网络抖动误杀下载。
- **断点续传真正生效**：下载器从 `URLSessionDownloadTask` 改为 `URLSessionDataDelegate` 边下边写到目标文件，中断后已接收字节真实落盘，重试时的 `Range` 续传不再从 0 重来，并完整支持 HTTP `200` / `206` / `416` 与装前 SHA-256 校验。
- **更新失败明确反馈**：将更新状态收拢为单一 `UpdateStatus` 状态机（`.installing` / `.installFailed`），彻底消除之前失败后界面悄悄回退到「有新版本」、用户只能一味重复点击的问题；主面板与设置页现在会以红色警告清晰展示具体失败原因，并提供「重试」与「打开下载页」兜底入口。

### 2. 专属学院统一识别 & 复用校园网账号
- **自动复用校园网登录账号**：连有线网或无线网时已经输入过的邮箱前缀（如 `xxx5525`），进入「宝藏站点 → 我的学院」会自动识别并锁定所属学院，不再要求重复搜索。
- **输入 8 位学号立即响应并持久化**：打通 `CollegeDirectory` 与 `GPACollegeDirectory` 的学院代码与名称别名映射，输入完整 8 位学号即刻锁定学院并记住学号，清晰显示识别来源（按账号识别 / 按学号识别 / 手动选择），随时可切换或恢复自动识别。

### 3. 文案与发布防呆加固
- **宝藏站点文案贴近日常**：将「英语竞赛 / 英語競賽」更名为 **「大英赛 / 大英賽」**。
- **版本单一真源与 CI 发布门禁**：新增根目录 `VERSION` 文件统一驱动全部打包脚本，`.github/workflows/release.yml` 强校验 `git tag == v$(cat VERSION)`、精确匹配产物路径并校验 zip 内 `Info.plist` 版本号与 `AppIcon.icns` / `Assets.car`，杜绝旧版本包套新版本号发出。

## 验证
- `make build`：`JLUGateCore`、`JLUGateNet`、`AppCompileCheck`、`AppCompatCompileCheck`、`jlugate-probe` 全部编译通过。
- `make test`：58 个测试套件、248 项测试全部通过（含新增的 `DownloadStallDetectorTests` 与统一学院识别测试）。
