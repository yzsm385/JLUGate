# JLU Gate 0.2.6

> 0.2.5 的收尾 + 一道"防再犯"的闸门。协议路径与实测能连的 v0.2.1 **逐字节一致**。

## 连接路径的回归证明

`git diff v0.2.1..HEAD` 对登录相关文件的结果：

| 文件 | 变化 |
|---|---|
| `DrcomCodec.swift`（登录包/摘要/保活） | **零改动** |
| `PacketLayout.swift` | **零改动** |
| `DrcomPacket.swift` / `MD5.swift` | **零改动** |
| `DrcomEngine.swift` | 只改选口（不碰报文） |

## 新增「钉子」测试（LoginPacketPinningTests）

固定输入下断言：

- 当前版：长度 375、摘要 A = MD5(03 01 salt password)、`0x38=20 03`、`0x6E="LIYUANYUAN"`、`0xB6="DrCOM"`
- 旧版：长度 346、尾部随机字节 == 传入值

以后任何改动碰坏协议，CI 立刻红，不会再"发出去才发现连不上"。

## 其它

- 自动选口新增 `preferWired`：**JLU.WIFI 模式下不会被有线抢走**；
- 移除旧版报文里多写的一个尾部字节（不属于该版本）；
- 离线端到端自测：`idle → discovering → challenging → authenticating → online → idle` ✅

## 验收建议

1. 装 0.2.6，先看设置里账号/网关是否还在（0.2.5 起不会再丢）；
2. 点连接；若失败，直接把 `~/Library/Logs/JLUGate/agent.log` 最后 30 行发我，
   日志里现在有「配置载入」「自动：优先有线/没有 IPv4」「错误码=0xXX」三类关键行。
