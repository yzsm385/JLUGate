# JLU Gate 0.2.6

> 这一版是 0.2.5 的收尾，外加一道“防再犯”的闸门。重点一句话：登录那条路，跟实测能连上的 v0.2.1 **逐字节一致**，没动过手脚。

## 登录这条路，到底有没有被动过

直接拿 `git diff v0.2.1..HEAD` 跟当初能连上的版本比，只看登录相关的文件，结果是这样：

| 文件 | 变化 |
|---|---|
| `DrcomCodec.swift`（登录包/摘要/保活） | **零改动** |
| `PacketLayout.swift` | **零改动** |
| `DrcomPacket.swift` / `MD5.swift` | **零改动** |
| `DrcomEngine.swift` | 只改选口（不碰报文） |

## 还埋了一道「钉子」测试（LoginPacketPinningTests）

这道测试的作用，是给登录报文钉死几个不变的量。固定输入下，它要看到：

- 当前版：长度 375、摘要 A = MD5(03 01 salt password)、`0x38=20 03`、`0x6E="LIYUANYUAN"`、`0xB6="DrCOM"`
- 旧版：长度 346、尾部随机字节 == 传入值

以后任何改动碰坏协议，CI 立刻红，不会再"发出去才发现连不上"。

## 顺带几处

- 自动选口加了个 `preferWired` 开关：**在 JLU.WIFI 模式下，不会被有线网卡横插一脚抢走**；
- 又清掉了旧版报文里多写的一个尾部字节（它本就不属于这个版本）；
- 离线端到端自测：`idle → discovering → challenging → authenticating → online → idle` ✅

## 想自己验一把的话

1. 装上 0.2.6，先去设置里看一眼账号/网关还在不在（0.2.5 起就不会再丢了）；
2. 点连接；要是没连上，别急，把 `~/Library/Logs/JLUGate/agent.log` 最后 30 行发给我就行。
   现在日志里有三类关键行，定位问题方便多了：「配置载入」「自动：优先有线/没有 IPv4」「错误码=0xXX」。
