# JLU Gate 0.1.0

首个公开版本：把吉林大学校园网的三种接入方式（有线 Dr.Com、JLU.PC 无线 Dr.Com、JLU.WIFI 网页认证）
收进一个菜单栏应用，并附带一套真实测量的网络体检工具。

## 能做什么

- **三网共用一套账号密码**：账号 = 邮箱 `@mails.jlu.edu.cn` 前缀；记住成功后不再反复输入
- **自动识别链路**：有线 / JLU.PC / JLU.WIFI 自动探测（发 1 个 challenge 判断，不做无谓认证）
- **保活与重连**：10 秒心跳、退避重连、休眠唤醒处理；被挤下线时提示并帮重进
- **网页认证不碰明文密码**：JLU.WIFI 走系统浏览器登录，程序只负责判定 204
- **网络详情**：网口/路由/DNS/VPN 快照，每个字段都有白话解释
- **网络体检**（真实测量，非占位）
  - 能不能上网：google / brave / duckduckgo / bing / baidu + 教务 / OA / 邮箱，逐层归因（DNS / TCP / TLS / HTTP）
  - 出口 IP：Cloudflare trace、ipify、ifconfig.me 三源交叉，带国旗
  - Cloudflare：国家 / 机房 / TLS / WARP
  - WebRTC：自实现 STUN（与浏览器同一机制），拿 XOR-MAPPED-ADDRESS
  - DNS 泄漏：`whoami.akamai.net` 反查解析出口，并对 fake-ip 如实说"比不出来"
  - 人机验证：reCAPTCHA / 国内镜像 / Cloudflare Turnstile / CF 挑战页可达性
  - IP 纯净度：ipinfo / ipapi / ipwho / BiliBili（+ 可选 IP2Location / MaxMind）
    交叉判断住宅 or 机房，并比对 DNS 出口与 IP 出口是否同国
  - 带宽三档：直连 / 默认出口 / 本地代理（自动探测本地端口）

## 安装

1. 解压后把 `JLU Gate.app` 拖进 `/Applications`
2. 首次打开若提示"无法验证开发者"：右键 → 打开，或到"系统设置 → 隐私与安全性"点"仍要打开"
3. 菜单栏出现盾牌图标 → 点开 → 设置账号密码

## 卸载

双击包内 `Uninstall JLU Gate.command`：会删掉 App、`~/Library/Application Support/JLUGate`、
`~/Library/Logs/JLUGate` 以及钥匙串里 `dev.jlugate.app` 的条目。

## 已知限制

- 本包为 ad-hoc 签名（无 Apple 开发者账号），因此密码保存在仅本用户可读的本地文件，不写钥匙串
- 路由保障的后台 helper（需要 root 签名）尚未提供，TUN 抢走默认路由时会在界面提示可复制的命令
- 网页认证与会话相关功能仍需要在真机（校园网环境）验证
