# JLU Gate 1.1.3

> 修 DNS 输入框：之前每格太窄，只放得下一个数字。

## 问题

向导第 3 步的 DNS 那一行，用的是和其它行不一样的布局（直接塞了个地址输入框进 Grid），
Grid 分给它的宽度不够，4 个小格被压缩成原来的一半宽——第一格显示 "10" 时只看得见一个数字，
输入也被挤得没法正常填。

## 这一版

- DNS 行改成和 IP / 子网掩码 / 网关完全相同的行结构，四个格子恢复标准宽度（42pt）；
- 编辑首选 DNS 时**保留备选 DNS**（以前一改首选就把逗号后面的备选冲掉了）；
- 设置页的 DNS 字段同样处理。

其余与 1.1.2 相同。

## 安装 / 升级

- macOS 26+：`JLU-Gate-v1.1.3.zip` / `.dmg`
- macOS 14/15：`JLU-Gate-v1.1.3-Compat.zip`
- 1.0.1 以后可在面板上点「更新」自动升级。
