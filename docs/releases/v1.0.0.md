# JLU Gate 1.0.0

> 第一个正式版：登录稳定、更新一键完成、DMG 拖拽安装。

## 安装

下载 `JLU-Gate-v1.0.0.dmg` → 打开 → 把 **JLU Gate** 拖进 **Applications** → 右键打开一次。

（首次打开仍会提示"无法验证开发者"：没有 Apple 开发者证书，右键 → 打开即可。）

## 更新（不用再手动退出、覆盖）

设置 → 更新 → **检查更新**：

- 有新版本时点 **「下载并安装」**；
- App 会自己下载 zip、解压，然后**退出 → 替换 /Applications 里的 App → 自动重新打开**；
- 前提：App 必须放在 `/Applications` 里（否则会提示你手动拖一次）。

不想自动替换也可以点「仅下载」。

## 1.0.0 之前修掉的关键问题（留档）

| 问题 | 真因 |
|---|---|
| 一直 `0x15` / ldap auth error | 启动预加载旧密码，且标成"本次输入"；旧密码从未成功过 |
| 更新后连不上 | 配置解码失败被静默丢弃，账号/网关被重置 |
| 点设置闪退 | AppKit 布局死循环（layout 里改自身 frame） |
| 拔网线后点重试闪退 | 缓存里还留着已消失的网口，拿它建通道 |
| 挂着不动自己跳到失败 | 存活探测用 gstatic/cloudflare，校园网里本来就不通 |
| 输入框每格只吃一个字符 | 跨字段刷新把正在输入的内容回灌覆盖 |
