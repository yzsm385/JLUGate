# JLU Gate 1.0.0

> 终于到 1.0 了。谢谢你一路陪着这个项目走到正式版——这一版的目标是把登录彻底稳住、让更新变成一键的事，安装也换成最常见的 DMG 拖拽。从早期"拔网线闪退、自己跳失败"那些折腾日子到现在，多亏大家一次次把日志发给我。

## 安装

下载 `JLU-Gate-v1.0.0.dmg` → 打开 → 把 **JLU Gate** 拖进 **Applications** → 右键打开一次就好。

（第一次打开还是会提示"无法验证开发者"：因为我没有 Apple 开发者证书，右键 → 打开就行，放心。）

> 这一份要求 **macOS 26 及以上**（用了 Liquid Glass 界面）。
> 系统更老（macOS 14 / 15）的同学：下 `JLU-Gate-v1.0.0-Compat.zip`，界面换成普通材质，功能一样，下面单独说。

## 更新（终于不用再手动退出、来回覆盖了）

打开 设置 → 更新 → **检查更新**：

- 有新版本时点 **「下载并安装」**；
- App 会自己把 zip 下载下来、解压，然后**退出 → 替换掉 /Applications 里的旧 App → 自动重新打开**；
- 前提是 App 得放在 `/Applications` 里（放别处的话，它会提示你手动拖一次）。

要是你不想让它自动替换，也可以只点「仅下载」。

## 走到 1.0 之前，一路修掉的关键问题（留档）

下面这些是早期最折腾人的几个坑，记在这里既是留档，也方便以后对照——

| 问题 | 真因 |
|---|---|
| 一直 `0x15` / ldap auth error | 启动预加载旧密码，且标成"本次输入"；旧密码从未成功过 |
| 更新后连不上 | 配置解码失败被静默丢弃，账号/网关被重置 |
| 点设置闪退 | AppKit 布局死循环（layout 里改自身 frame） |
| 拔网线后点重试闪退 | 缓存里还留着已消失的网口，拿它建通道 |
| 挂着不动自己跳到失败 | 存活探测用 gstatic/cloudflare，校园网里本来就不通 |
| 输入框每格只吃一个字符 | 跨字段刷新把正在输入的内容回灌覆盖 |

## 旧版适配包（macOS 14+）

主包用了 macOS 26 才有的 Liquid Glass，老系统上一调 `glassEffect` 就 unrecognized selector 崩。
所以单独出了 `JLU-Gate-v1.0.0-Compat.zip`：

- 最低系统 **macOS 14 (Sonoma)**；
- 界面不用 Liquid Glass，全换成普通材质（`.regularMaterial` + 描边），看着朴素但不会崩；
- 和主包**同名同 bundle id**（`dev.jlugate.app`），两份不要同时装——启动守卫会把同 id 的旧进程顶掉；
- 连接、保活、体检、站点这些功能完全一样（共用同一份冻结的 `Sources/`，没动登录链路）。

源码在仓库里的 `App-Compat/`，和 `App/`（新版）并列；分别 `make app-bundle` / `make app-compat` 出两个 `.app`。

## 连接路径冻结

跟登录直接相关的这些文件——`DrcomEngine` / `AuthCoordinator` / 通道 / `DrcomCodec` / `PacketLayout` / `DrcomPacket` / `MD5`——
已经由 `scripts/connection-guard.sh` 冻结，CI 会拦下任何没说清楚的改动，免得好心改出新的登录问题。

193 tests · 三个离线自测 · 隐私扫描 · 连接冻结检查 全绿。
