# JLU Gate 0.2.2

> 这一版给你加了个“一键检查更新”，顺手把 Release 正式对外了——以后只发 0.2.x，0.1.x 那几个连不上的旧版本已经下架，省得你再撞上。

## 检查更新，不用再自己翻 releases 了

设置页里多了一栏「更新」：

- **检查更新** → 去读 GitHub 上最新的 Release（结果缓存 1 小时，免得老去问、被限流）；
- 有新版本的话：显示 `有新版本 v0.2.2`，再配个 **下载**按钮（点了直接下 zip），省得你自己跑去 releases 页翻；
- 已经是最新了：就显示「已是最新」，让你踏实。

至于自动下载、静默安装那种事，我没做：菜单栏小工具没必要这么霸道，更不想在你不知情的时候把 App 偷偷换掉。

## Release 的规矩（按你之前提的要求）

整理出来是这样：

| 版本 | 状态 |
|---|---|
| 0.1.0 ~ 0.1.4 | **已下架**：登录报文版本错误，连不上 |
| 0.2.0 | 已发布：登录恢复 + 站点合集 |
| 0.2.1 | 已发布：隐私加固 + WebVPN 一键入口 |
| **0.2.2** | **最新**：检查更新 |

之前 Release 老失败的那个毛病也一并修了：工作流把打包资产名写死成了 `0.1.0`，版本号一变，文件名就对不上、发不出来。
现在改成按实际构建出来的产物取名，顺手把 0.1.x 那几个旧 Release 也清掉了。

## 装上 / 升级一下

三步走：

1. 下载 `JLU-Gate-v0.2.2.zip`，解压；
2. 先退出旧版（菜单栏 → 退出），把 `JLU Gate.app` 拖进 `/Applications` 覆盖；
3. 右键 → 打开（未签名）。

放心，配置和密码都躺在 `~/Library/Application Support/JLUGate`，覆盖安装不会弄丢。
