# JLU Gate 0.2.2

> 一键检查更新 + Release 正式对外（0.2.x 才发布，0.1.x 连不上的版本已下架）。

## 更新不再繁琐

设置页新增「更新」一栏：

- **检查更新** → 读 GitHub 最新 Release（1 小时缓存，避免限流）
- 有新版本：显示 `有新版本 v0.2.2` + **下载**按钮（直接开 zip），不用自己去 releases 页翻
- 已是最新：显示「已是最新」

不做自动下载/静默安装：菜单栏工具没必要，也不会在你不知情时替换 App。

## Release 规则（按你的要求）

| 版本 | 状态 |
|---|---|
| 0.1.0 ~ 0.1.4 | **已下架**：登录报文版本错误，连不上 |
| 0.2.0 | 已发布：登录恢复 + 站点合集 |
| 0.2.1 | 已发布：隐私加固 + WebVPN 一键入口 |
| **0.2.2** | **最新**：检查更新 |

之前几次 Release 失败的原因也修了：工作流把资产名写死成 `0.1.0`，版本变化后打包文件对不上。
现在按实际构建产物取，并顺手清理 0.1.x 的旧 Release。

## 安装 / 升级

1. 下载 `JLU-Gate-v0.2.2.zip`，解压；
2. 先退出旧版（菜单栏 → 退出），把 `JLU Gate.app` 拖进 `/Applications` 覆盖；
3. 右键 → 打开（未签名）。

配置与密码都在 `~/Library/Application Support/JLUGate`，覆盖安装不会丢。
