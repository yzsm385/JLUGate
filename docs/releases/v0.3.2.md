# JLU Gate 0.3.2

> 修两个让人一愣的问题：保存后地址全被塞进第一个框，还有明明填对了却提示"填错了"。

## 原因

输入框内部用中间点拼地址，写成 `203·0·113·11`，配置里保存的也是这个格式；
可解析的时候只认 ASCII 点 `.`：`split(separator: ".")` 找不到 `·`，
整串就一股脑落进第 1 个框。`IPv4Address` / `MACAddress` 也一样只认 `.` / `:`，
于是保存时校验过不了，提示"填错了"。

## 现在

- 拆分的时候同时认 `·`、`.`、`:`、还有全角的 `．`；
- 要是没有分隔符（比如直接粘贴 `203011311`），就按组长度切：IPv4 每 3 位、MAC 每 2 位；
- 粘贴或整段输入会**摊到各个框里**，不会再全塞进第一个；
- 解析地址时中间点也能认出来，保存时不会再误报格式错误；
- MAC 用 `-` 分隔也能解析了（原来那个判断写错了）。

## 测试

新增 3 组共 6 条：分隔符拆分、无分隔符切段、中间点/全角点解析；
189 tests 全绿，三个离线自测和隐私扫描都过。
