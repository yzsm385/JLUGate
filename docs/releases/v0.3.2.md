# JLU Gate 0.3.2

> 修"保存后地址全被塞进第一个框"，以及"填好了却提示填错"。

## 原因

输入框内部用中间点拼地址 `203·0·113·11`，配置里保存的也是这个格式；
但解析只认 ASCII 点 `.`：`split(separator: ".")` 找不到 `·`，整串就落进第 1 个框。
`IPv4Address` / `MACAddress` 同样只认 `.` / `:`，于是保存时校验失败，提示"填错了"。

## 现在

- 拆分同时接受 `·`、`.`、`:`、全角 `．`；
- 没有分隔符（比如粘贴 `203011311`）按组长度切：IPv4 每 3 位、MAC 每 2 位；
- 粘贴/整段输入会**摊到各段**，不会全塞进第一个框；
- 解析地址时中间点也能识别，保存不再误报格式错误；
- MAC 用 `-` 分隔也能解析（原来那个判断写错了）。

## 测试

新增 3 组共 6 条：分隔符拆分、无分隔符切段、中间点/全角点解析；
189 tests 全绿，三个离线自测与隐私扫描通过。
