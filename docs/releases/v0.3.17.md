# JLU Gate 0.3.17

> 修「挂着没动，它自己从已连接跳到失败」。

## 你的日志证明了什么

```
14:15:32  保活 b 无应答（第 1 次）      ← 几乎每 30 秒一次
14:25:57  保活 a 无应答（第 2 次）
14:26:38  保活 b 无应答（第 3 次）
14:26:59  认证失败：认证服务器 10.100.61.3 无响应
14:27:06  online（重连成功）
```

吉大网关本来就不回保活 b。引擎在无应答时会做一次"网络到底通不通"的确认，
而它用的是 `connectivitycheck.gstatic.com` 和 `cp.cloudflare.com`——
**这两个在校园网里经常解析/连接失败**，于是网络明明通着，也被判成断线，
拆掉会话重连。你看到的状态跳变就是这么来的。

## 现在

存活确认改成**校内优先**：

1. 问校内 DNS（10.10.10.10）能不能应答；
2. 给认证服务器 10.100.61.3 发 challenge，看有没有回执；
3. 两者都失败，才用外部 204 兜底。

另外：单次探测失败不再直接把界面打红（连续 2 次才算），并新增状态变化日志
（`状态：online → failed`），下次能直接对账。

连接协议文件仍未改动（冻结检查通过）。
