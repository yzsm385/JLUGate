# JLU Gate 0.3.17

> 这版修一个挺无厘头的问题：明明挂着没动，程序却自己从"已连接"跳到"失败"。

## 你的日志说明了什么

```
14:15:32  保活 b 无应答（第 1 次）      ← 几乎每 30 秒一次
14:25:57  保活 a 无应答（第 2 次）
14:26:38  保活 b 无应答（第 3 次）
14:26:59  认证失败：认证服务器 10.100.61.3 无响应
14:27:06  online（重连成功）
```

事情是这样的：吉大网关本来就不回"保活 b"。引擎发现没应答时，会再做一次"网络到底通不通"的确认，
可它问的是 `connectivitycheck.gstatic.com` 和 `cp.cloudflare.com`——
**这两个在校园网里本来就容易解析或连接失败**。于是网络明明好好的，却被当成断了，
会话被拆掉重连，你看到的状态跳变就是这么来的。

## 现在怎么办

存活确认改成了**校内优先**：

1. 先问校内 DNS（10.10.10.10）能不能应答；
2. 再给认证服务器 10.100.61.3 发 challenge，看有没有回执；
3. 两样都不行，才退到外部 204 兜底。

还有两个小调整：单次探测失败不再立刻把界面打红（要连续 2 次才算），并且加了状态变化日志
（`状态：online → failed`），下次出问题能直接对上账。

连接协议文件没有改动（冻结检查通过）。
