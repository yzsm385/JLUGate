# JLU Gate 1.1.0

> 这一版把界面文字全部换成了新的温暖版，并且支持 **简体中文 / 繁體中文 / English** 三种语言——按系统语言自动选。

## 这一版改了什么

### 1. 三种语言，跟着系统走

- 系统首选语言是中文（简体）→ 简体中文；
- 繁体（zh-Hant / zh-TW / zh-HK / zh-MO）→ 繁體中文；
- 其他 → English。
- 想手动指定，可以在终端里 `JLUGATE_LANG=zh-Hant open -a "JLU Gate"`（开发/调试用）。

711 条界面文案全部收进了语言表，缺条目会回退简体，不会出现空白。

### 2. 界面文字换成温暖版

状态卡、向导、设置、体检、站点、错误提示……所有看得到的句子都换成了新版（带 emoji 的那种）。
顺手改了几处旧说法：密码统一写成「统一身份认证密码」，自助平台的入口/步骤按实际界面写清楚。

### 3. 布局跟着长文案调整

- 明细行的标签列加宽，英文长标签可以换两行，值列保持对齐；
- 底部工具栏恢复一行 6 个，按钮去掉 emoji（有 SF Symbol 图标就够了），不再把文字挤到下一行；
- 「新手引导」的按钮改成竖排，英文长句不会被截断。

### 4. 连接相关的修复（含 1.0.2 / 1.0.3）

- 会话掉了能自己发现、自己重连（在线巡检 + 204 判定 + 退出/重开自动恢复）；
- 静默丢包（网关不重定向、只是不回包）也能在约 100 秒内发现；
- 诊断里会带上网关未知报文和保活 B 首包的字节，方便继续查协议差异。

## 安装

| 你的系统 | 下哪个 |
|---|---|
| macOS 26 及以上 | `JLU-Gate-v1.1.0.zip` / `.dmg` |
| macOS 14 / 15 | `JLU-Gate-v1.1.0-Compat.zip` |

## 升级

1.0.1 及以后可以在面板上点「更新」自动升级；1.0.0 建议手动下主包（旧更新器会挑到 Compat 包）。
