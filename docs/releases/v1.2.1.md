# JLU Gate 1.2.1

> 给「早八提醒」留好课表接入点：**接上课表后，有课才催、没课就劝你睡懒觉**。现在还没课表数据，行为不变。

## 这一版做了什么

- 新增 `TimetableLookup` 协议：以后课表功能接进来，只要实现
  `hasClassAtEight(on:)`（返回 true / false / nil），提醒就会自动变聪明：
  - 早上 7:30–8:30 **有课** → 「☀️ 早八时间到！」（R05）
  - 早上 7:30–8:30 **确定没课** → 「🛌 今天没有早八，睡个美美的回笼觉吧」（R06）
  - **不知道 / 还没接课表** → 保持现状：工作日默认按有早八提醒
- `DormSchedule.care(at:timetable:)` 接受可选的课表；不传就是现在的行为。
- 单测覆盖了「有课 / 没课 / 不知道 / 没接课表」四种情况。

## 之后怎么接

课表数据准备好后，实现一个 `TimetableLookup`（按北京时间的当天判断 8 点有没有课），
传给 `DormSchedule.care(at:timetable:)` 即可，不需要再改文案和 UI。
