# JLU Gate 0.3.0

> 输入框回到 **0.2.2 的实现**——就是你用着稳定的那套。

## 为什么回退

0.2.7 我改 `updateNSView` 时，把 0.2.2 的保护条件 `!container.isEditing` 去掉了。
SwiftUI 会把**上一次的旧值**回调给控件；旧值和内部记录对不上，
就被当成"外部改动"回灌——结果每格只吃一个字符，光标还跳走。

现在直接恢复 v0.2.2 的 `AddressFields.swift`（AppKit 分段框 + 编辑中不回灌），
只保留纯展示改动：段宽、标签宽度、字段含义内联。

## 连接：与 0.2.2 一致

| 文件 | 与 v0.2.2 比 |

| `DrcomCodec.swift` | 相同 |
| `PacketLayout.swift` | 相同 |

## 不会崩

- 恢复的这版包含 0.1.3 的布局死循环修复（layout() 不改自身 frame）；
- 本地打开向导/设置各一次：进程存活，`crash-stack.log` 无新增；
- `codesign --verify` 通过。
