# JLU Gate 1.1.1

> 1.1.0 的界面修补：加了「语言」切换、修好英文版挤在一起的地方。功能不变。

## 新增：语言可以手动了

设置页最上面多了「语言 / Language」：

- 跟随系统（默认）
- 简体中文 / 繁體中文 / English

选完立刻生效（面板按键重建一次），不用重启。系统语言不是中文时，默认走 English。

## 修好的排版

- **底部工具栏**：英文 Diagnostics / Health Check 不再挤在一起（按钮去掉 emoji、字号自适应、间距放宽）；
- **子网掩码 / 登记 MAC**：英文长标签不再冲出右边，改成换行并和输入框对齐；
- **选网卡的下拉框**：标题单独一行，选中值不会再被挤成一个字母；
- **新手引导卡片**：两个按钮竖排，英文长句不再被截断成「Portal Shortcut…」；
- **地址输入框里的数字**：默认居中显示（macOS 的单行 TextField 会忽略居中设置，这里单独处理了）；
- **卡片圆角**：状态卡 18 → 26、内层卡片 12 → 18、向导卡片 24、引导卡 14，整体更接近圆润的大圆角风格。

> 菜单栏弹窗最外层的圆角由 macOS 的 NSPopover 决定，应用改不了；能调的是里面这些卡片。
> 真要把最外层换成自定义圆角窗口，需要放弃 NSPopover（之前的自定义 NSWindow 在显示周期里崩过），不建议现在动。

## 安装 / 升级

- macOS 26+：`JLU-Gate-v1.1.1.zip` / `.dmg`
- macOS 14/15：`JLU-Gate-v1.1.1-Compat.zip`
- 1.0.1 以后可以在面板上点「更新」自动升级。
