# JLU Gate 0.3.12

> 修「点了菜单栏图标没反应、也退不掉」。

## 可能的原因（两条都修了）

1. **另一份副本在抢同一个图标**：`/Applications` 里那份旧版（build `202611031650`）
   如果还在跑，会有两个状态栏项目，点到的可能是没绑面板的那个。
   现在启动时自动结束同 bundle id 的其他副本，只保留当前这份。
2. **右键菜单根本没弹出来**：之前用的是"临时挂 `statusItem.menu` + `performClick`"，
   这种方式在部分系统版本上什么都不显示。改成 `menu.popUp(at:in:)`。
3. 左键：如果按钮还没进窗口（刚重启/刚登录），会记日志并 400ms 后自动重试。

## 兜底退出方式

- 新增主菜单：**⌘Q 退出**；
- 菜单栏图标右键 → 退出 JLU Gate；
- 实在不行，终端执行：`pkill -f "JLU Gate.app/Contents/MacOS/JLUGate"`。

## 如果点图标仍然没反应

请先只保留一份 App：

```
rm -rf "/Applications/JLU Gate.app"     # 删掉旧版
```

再把新版放进 `/Applications`，在 系统设置 → 通用 → 登录项与扩展 里确认只有一份。
如果还有问题，导出的诊断文件里现在会带 `面板：按钮还不在窗口里，稍后重试` 这类日志，发我即可。
