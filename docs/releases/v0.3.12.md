# JLU Gate 0.3.12

> 这版专门收拾一件怪事：点了菜单栏图标没反应，想退还退不掉。

## 可能的原因（几条都修了）

1. **另一份副本在抢同一个图标**：`/Applications` 里那份旧版（build `202611031650`）
   要是还在跑，状态栏里就会有俩图标，你点中的那个，很可能是没绑面板的那一个。
   现在启动时会自动结束同 bundle id 的其他副本，只留当前这一份。
2. **右键菜单压根没弹出来**：以前用的是"临时挂 `statusItem.menu` + `performClick`"，
   这套办法在部分系统版本上什么都不显示。换成 `menu.popUp(at:in:)` 就稳了。
3. 左键这边：要是按钮还没进窗口（刚重启或刚登录那种），会记一行日志，过 400ms 自己再试一次。

## 实在退不掉的兜底办法

- 主菜单里新增了：**⌘Q 退出**；
- 菜单栏图标右键 → 退出 JLU Gate；
- 都不行的话，终端里执行：`pkill -f "JLU Gate.app/Contents/MacOS/JLUGate"`。

## 如果点图标还是没反应

先保证只剩一份 App：

```
rm -rf "/Applications/JLU Gate.app"     # 删掉旧版
```

再把新版放进 `/Applications`，到 系统设置 → 通用 → 登录项与扩展 里确认只有一份。
要是还有问题，导出的诊断文件里现在会带上 `面板：按钮还不在窗口里，稍后重试` 这类日志，发给我就行。
