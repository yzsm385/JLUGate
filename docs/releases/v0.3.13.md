# JLU Gate 0.3.13

> 这版让"双击打开 App"也能自动连上，并且把第一次尝试从 1.5 秒压到了 **1 秒**。

## 为什么以前双击打开不会自动连

从 0.3.5 起，启动时不再把保存的密码读进内存（为的是别拿旧密码反复去撞服务器）。
可这带来个副作用：启动判断 `hasPassword` 时只看内存，那自然永远为假——于是自动连接被跳过，
只能干等着被动观测，或者等你手动点一下。

现在换了个判断：**账号存在 + 密码被标成"已验证" + 本地确实有密码**，就算作有凭据，
启动后直接走自动连接流程（跟开机自启是同一条路）。

## 自动连接的节奏

| | 0.3.12 | 0.3.13 |
|---|---|---|
| 第 1 次 | 1.5 秒 | **1 秒** |
| 重试间隔 | 2 秒 | 2 秒 |
| 最多 | 5 次 | 5 次 |

一旦连上、或者已经有连接在跑，就立刻停手；5 次都失败才罢休并写日志。

## 前提

- 设置里「自动连接」开着；
- 密码**成功登录过至少一次**（这样才会被标成已验证，允许自动复用）；
- 有线 / JLU.PC 的静态参数已填全。

193 tests / 三个离线自测 / 隐私扫描 / 连接冻结检查 全绿。
