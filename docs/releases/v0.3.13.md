# JLU Gate 0.3.13

> 双击打开 App 也会自动连接；第一次尝试从 1.5 秒缩到 **1 秒**。

## 为什么之前双击打开不自动连

0.3.5 起，启动时不再把保存的密码读进内存（为了防止拿旧密码反复撞服务器）。
副作用是：启动判断 `hasPassword` 只看内存 → 永远为假 → 自动连接被跳过，
只能被动观测或等你手动点。

现在：**账号存在 + 密码被标记为"已验证" + 本地确实有密码**，就算作有凭据，
启动后直接进入自动连接流程（和开机自启走的是同一条路径）。

## 自动连接的节奏

| | 0.3.12 | 0.3.13 |
|---|---|---|
| 第 1 次 | 1.5 秒 | **1 秒** |
| 重试间隔 | 2 秒 | 2 秒 |
| 最多 | 5 次 | 5 次 |

连上或已有连接在进行就立刻停止；5 次都失败才停手并写日志。

## 前提

- 设置里「自动连接」开着；
- 密码**成功登录过至少一次**（这样才会被标记为已验证，允许自动复用）；
- 有线 / JLU.PC 的静态参数已填全。

193 tests / 三个离线自测 / 隐私扫描 / 连接冻结检查 全绿。
