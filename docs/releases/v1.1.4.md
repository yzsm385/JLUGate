# JLU Gate 1.1.4

> 向导第 3 步简化：**用户实际只需要填 IP 和 MAC**，其余都给好默认值、随时能改。

## 这一版

### DNS：三选一

不再是四个空格让人对着抄，改成下拉：

1. **学校 DNS（10.10.10.10）**：默认，校内首选；
2. **公共 DNS（223.5.5.5）**：校内 DNS 不通时用；
3. **自定义…**：选它才出现输入框，自己填。

### 网关：跟着 IP 自动算

IP 填完（四段齐了）就自动补成同网段的 **x.x.x.254**，不用手打；
手动改过网关之后，再改 IP 也不会把你的改动冲掉。

### 子网掩码：默认 255.255.255.0

进入这一步就填好了，绝大多数宿舍就是这个值，不对再改。

## 为什么

学校发的通知单上，真正每台机器不同的是 **IP 和登记 MAC**；掩码、网关、DNS 基本都是统一值。
现在只需要填那两个，剩下的确认一下就行。

## 安装 / 升级

- macOS 26+：`JLU-Gate-v1.1.4.zip` / `.dmg`
- macOS 14/15：`JLU-Gate-v1.1.4-Compat.zip`
- 1.0.1 以后可在面板上点「更新」自动升级。
