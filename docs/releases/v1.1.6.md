# JLU Gate 1.1.6

> 新手引导里加了一条提醒：换寝室的时候记得截图。

## 新增提示

学校在换寝室时可能会弹出一个**「用户迁移」**页面，上面写着：

- 网卡的物理地址（MAC）
- 原来的 IP
- 迁移之后的 IP

看到它请**截图保存**——之后填网络参数、去自助平台登记 MAC 都要用到这几个数。
这条提示已经加进「萌新指南」卡片（设置页顶部、向导里都能看到），简体 / 繁體 / English 三语都有。

其余与 1.1.5 相同。

## 安装 / 升级

- macOS 26+：`JLU-Gate-v1.1.6.zip` / `.dmg`
- macOS 14/15：`JLU-Gate-v1.1.6-Compat.zip`
- 1.0.1 以后可在面板上点「更新」自动升级。
