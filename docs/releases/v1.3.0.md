# JLU Gate 1.3.0

> 主页瘦身、详情页只留信息、测量入口统一收进「体检」，另外加了放学提醒。

## 主页

- **去掉「出口」那一行**（太占地方），出口信息只在「详情」里看；
- 底栏按钮顺序调整：**诊断** 挪到 **设置** 左边。

## 详情页：只显示信息

- 认证通道、Ping、测速的**按钮全部移除**，页面只展示当前信息与最近一次结果；
- 想重新测量，去「体检」页。

## 体检页：新增「🧰 网络诊断」

从详情页搬过来的三块测量入口，现在都在体检页底部：

- 认证通道延迟（直连 vs 经默认出口）；
- Ping；
- 三档测速（含「有没有绑到物理网卡」的提示）。

## 新增：放学提醒

工作日 **17:00–18:00**，主面板会出现一条：「🔔 放学啦！今天的课辛苦啦～去食堂吃顿热乎的 🍜，或者回宿舍躺一小会儿 🛌」。
和睡觉提醒一样，**只按北京时间**判断，三语都有。

## 安装 / 升级

- macOS 26+：`JLU-Gate-v1.3.0.zip` / `.dmg`
- macOS 14/15：`JLU-Gate-v1.3.0-Compat.zip`
- 1.0.1 以后可在面板上点「更新」自动升级。
