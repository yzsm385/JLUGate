# JLU Gate 1.4.6

> 体检页面三个可读性修复。

## 修复

- `公网（阿里 DNS）` 标签之前按第一个空格截断，显示成 `公网（阿里`；
  现在只去掉末尾 IP，右括号完整显示。
- 出口 IP 的「地理位置 / 归属运营商 / ASN / IP 类型 / 备注」右列改为右对齐，
  和左栏标签分开。
- 「链路延迟」和上述归属行的左栏标签由 tertiary 淡灰改为 secondary 10pt medium，
  不再看不清。

## 安装 / 升级

- macOS 26+：`JLU-Gate-v1.4.6.zip` / `.dmg`
- macOS 14/15：`JLU-Gate-v1.4.6-Compat.zip`
- 1.0.1 以后可在面板上点「更新」自动升级。
