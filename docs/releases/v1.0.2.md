# JLU Gate 1.0.2

> 这一版专治"老是断连":以前会话掉了 App 还显示在线,现在能自己发现、自己重连。

## 这一版改了什么

### 1. 掉线后自动重连

以前会话断了,App 会一直停在"已连接",得手动点「登录」或重开 App。
现在:

- 认证失败且属于**网络类**原因(超时 / 网关无应答 / 通道异常),会按 **3s → 6s → 12s → 24s → 30s** 自动重试,最多 6 次;
- 密码错、MAC 不符、端口被占这类重试也没用的问题**不会**瞎重试,照旧提示你处理;
- 连上以后计数清零,下次掉线重新开始。

### 2. 在线巡检:外网真断了能发现

在线期间每 25 秒走一次真实 204 探针。连续两次被门户拦下(说明会话已经失效),
就自动重新认证——不用等你发现网卡了再动手。

### 3. 存活判定只认 204

以前判断"网络还通不通"用的是校内 DNS / 网关——可它们在**没认证的时候也是通的**,
于是"会话掉了"被当成"在线",永远不重登。现在只认 204:被重定向到门户页就算掉线。

### 4. 诊断更清楚

- 网关发来的"不认识"的包,第一次遇到会把前 32 字节记进日志(方便定位协议差异);
- 「端口占用」不再把 JLU Gate 自己报成"被其它进程占用",会写"由 JLU Gate 自己占用(认证通道,正常)"。

## 安装

| 你的系统 | 下哪个 |
|---|---|
| macOS 26 及以上 | `JLU-Gate-v1.0.2.zip` / `.dmg`(Liquid Glass) |
| macOS 14 / 15 | `JLU-Gate-v1.0.2-Compat.zip`(普通材质,功能一样) |

第一次打开如提示"无法验证开发者":系统设置 → 隐私与安全性 → 仍要打开。

## 升级

- **1.0.1 及以后**:面板上点「更新」就能自动换到这一版;
- **1.0.0**:也能一键更新,但旧更新器会挑到 Compat 包;想要主包请手动下 `JLU-Gate-v1.0.2.zip`;
- **0.3.x 及更早**:没有自动更新,手动下载替换。
