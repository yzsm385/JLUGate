# JLU Gate 0.2.7

> 三个"用起来才发现"的问题：跨字段清空、自动读取失效、没参数时只说失败。

## 1. 在子网掩码里打字，IP 被清空

分段输入框每次刷新都拿 SwiftUI 的当前值回灌；在别的字段输入触发刷新时，
IP 字段拿到的是还没同步的旧值（空），于是把已填内容清掉。

现在由控件自己记「最后写出去的值」，只有真正的外部改动（载入配置 / 清空）才回灌；
用户输入与跨字段刷新一律不动内容。

## 2. 自动读取 IP/掩码/网关恢复

- 读参数时不再随便取"第一块能用的网卡"（那通常是 Wi‑Fi），
  顺序改为：**正在用的 → 有线且有地址 → 任一块有地址**；
- 进入向导「网络参数」且字段为空时，自动读一次系统当前配置（仅在网卡是手动配置时可信）。

## 3. 有线没填参数：直接让你填，而不是说"连接失败"

- 检测到「有线插着但没有 IPv4」→ 自动打开向导网络参数页；
- 页首写明：`有线网卡 enX 还没有 IP 地址。把学校分的静态参数填进来（或把网卡改成 DHCP）再连。`
- 不再出现"你压根没填，却告诉你认证失败"这种话。

## 验收

1. 打开向导网络参数：IP/掩码/网关应已自动带出（本机实测已填好）；
2. 在掩码框里随便改几位，IP 不会被清空；
3. 自动模式 + 有线无地址：应直接跳到这一页并给出提示。
