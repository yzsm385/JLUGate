# JLU Gate 0.2.7

> 这一版收拾三个用着用着才发现的小别扭：跨字段会把对方清空、自动读取罢工、没填参数时只会甩一句失败。

## 1. 在子网掩码里打字，IP 却被清空了

分段输入框每次刷新都会拿 SwiftUI 当前的值往回灌；你在别的字段一敲，触发了一次刷新，
IP 字段拿到的却是还没同步上来的旧值（空的），结果你刚填的内容就被清掉了。

现在改成由控件自己记「最后写出去的值」，只有真正的外部改动（载入配置 / 清空）才回灌；
你自己输入、或者跨字段刷新，一律不碰内容。

## 2. 自动读取 IP/掩码/网关，又回来了

- 读参数时不再随便抓「第一块能用的网卡」（那通常是 Wi‑Fi），
  顺序改成：**正在用的 → 有线且有地址 → 任一块有地址**；
- 进入向导「网络参数」且字段都空着时，自动读一次系统当前的配置（只有网卡是手动配置时才信得过）。

## 3. 有线没填参数：直接让你填，而不是甩一句"连接失败"

- 检测到「有线插着但没有 IPv4」→ 自动打开向导网络参数页；
- 页首写明：`有线网卡 enX 还没有 IP 地址。把学校分的静态参数填进来（或把网卡改成 DHCP）再连。`
- 再也不会出现"你压根没填，它却告诉你认证失败"这种话。

## 验收

1. 打开向导网络参数：IP/掩码/网关应该已经自动带出来了（本机实测确实填好了）；
2. 在掩码框里随便改几位，IP 不会被清空；
3. 自动模式 + 有线无地址：应该直接跳到这一页并给出提示。
