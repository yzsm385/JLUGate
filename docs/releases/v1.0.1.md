# JLU Gate 1.0.1

> 这一版两件事：把 macOS 14 上"菜单栏图标老往左边跑"根治掉；再给新生把"我该填什么"讲明白。

## 这一版改了什么

### 1. 菜单栏图标不再跑到左边（macOS 14 真机已确认）

之前图标会挤在 App 菜单里（夹在「显示」和「前往」中间），或者紧挨着「帮助」，面板跟着跑到左边。
覆盖安装没用——位置不保存在 App 包里。

现在：启动后量一次图标在屏幕上的真实位置，不在右半边就换一个全新的 autosaveName 重建，
并写入 AppKit 自己的位置偏好，把它排到右上角那一排；万一反而更靠左，会自动撤回。
登录项拉起、解锁回来时还会再补量一次。

### 2. 新生引导：不会填？去自助平台查

「设置」页顶部、向导的账号步与网络参数步，都加了一张卡片，点一下就能打开
[校园网自助平台](https://ip.jlu.edu.cn/pay)，展开就是步骤：

- 用**校园卡号**（录取通知书上那串，如 `20220501324`）＋ **6 位数字密码**（吉大 V 卡）＋ 验证码登录；
- 「**查询信息**」里是 IP、网关、DNS——**这里没有 MAC**；
- 登记 MAC 走另一个入口：「**变更 MAC**」；
- 自己这台 Mac 的 MAC 在哪看：有线是「设置 → 网络 → 网卡 → 详细信息 → MAC」，
  Wi-Fi 是「设置 → Wi-Fi → 已加入的网 ⋯ → MAC」。

三套密码也分开列了：V 卡（校园卡号 + 6 位数字）、吉大邮箱（独立密码）、统一身份认证（教务 / VPN / 本 App）。

### 3. 欠费与充值（连不上时经常是这个）

- 余额 **-10 元、0 元**都还能正常上；到 **-20 元**就断（有线 / JLU.PC / JLU.WIFI 都一样）；
- 充值档位只有 **20 / 40 / 100**，钱从校园卡余额里扣；
- 欠 20 的时候充 20（变成 0）不算数，要充 **40**（余额变成 +20）才能用。

### 4. JLU.WIFI 不再让你填静态参数

它本质是 HTTP 网页认证、地址由 DHCP 动态分配，**一个 IP / 掩码 / 网关 / MAC 都不用填**。
设置里的引导卡会跟着「接入方式」变：选 JLU.WIFI 就只讲"不用填"，选有线 / JLU.PC 才讲静态参数。

### 5. 网页认证入口多一道检查

有人开个热点、把门户页指向自己的站点，同学一输账号就中招。现在：

- 登录页地址不是 `*.jlu.edu.cn` 时**不会自动打开浏览器**，面板上会写明原因，留一个「仍要打开这个页面」；
- 认准 Wi-Fi 名字：只有 `JLU.PC` 和 `JLU.WIFI`，名字要一模一样（大写、中间一个点），
  同名网络先确认是不是学校的。

> 说明：macOS 10.15 起读取当前 Wi-Fi 名字（SSID）需要「定位」权限，没授权时系统直接不给，
> 所以 App 没有拿名字做硬校验（也不想为了这个弹定位授权）——改用"入口域名 + 名字自己认"这条线。

### 6. 面板高度跟着内容走

以前子页面不管内容多少都按 520 点排，短页面（连接状态、网页登录…）下面会空一大块。
现在先量内容高度，短就短、超过 520 才开始滚动，面板窗口也跟着变——不再有多余的留白。

### 7. 主面板就能一键更新

面板上多了一行「更新」：

- 点一下 → 去 GitHub 查最新 Release → **自动下载 → 退出 → 替换 /Applications 里的 App → 自动重新打开**；
- 下载的 zip、解压出来的副本、安装脚本，装完**全部自动删掉**，不占你的磁盘；
- 进度会显示在那一行（下载中 / 解压中 / 准备退出）；已经是最新就说一句"已是最新版本"；
- 启动 5 秒后会安静地查一次，有新版本会在那一行提示。

另外修了一个会装错包的坑：同一个 Release 里有新包（macOS 26）和适配包（macOS 14），
现在会按当前版本挑对应的 zip——**适配包绝不会拿到新包兜底**，免得装完打不开。

### 8. 顺手的小修

- 「站点合集」里的校园网自助服务不再预填统一账号：那平台用的是校园卡号 + 6 位 V 卡密码，
  复制过去反而让人以为密码错了。

## 安装

| 你的系统 | 下哪个 |
|---|---|
| macOS 26 及以上 | `JLU-Gate-v1.0.1.zip`（Liquid Glass 界面） |
| macOS 14 / 15 | `JLU-Gate-v1.0.1-Compat.zip`（普通材质，功能一样） |

解压后把 **JLU Gate.app** 拖进「应用程序」；第一次打开会提示"无法验证开发者"，
到「系统设置 → 隐私与安全性」拉到底点「仍要打开」，输一次密码即可。往后不会再问。

两个包同名同 bundle id，**别同时装**。

## 升级

已经在用 1.0.0 的：打开 设置 → 更新 → 检查更新，让它自己替换，或者直接下新包覆盖
（在跑的旧进程会被启动守卫顶掉）。
