# JLU Gate 0.1.1

> 这版只做一件事：把登录流程里最要命的那个坑填平。一句话——别再让程序偷偷拿你上次的旧密码去敲门了。

## 那个"怎么点都连不上"的问题

**你是这样的**：密码明明没输错，服务器却一口咬定 `ldap auth error`；重启也好、重试也好，永远是同一个结果，特别劝退。

**根子在我自己代码里**：程序把“保存过的密码”在三处地方偷偷复用了，却没告诉你它复用的是哪一份——

1. 向导一打开，就直接把旧密码塞进输入框（显示成一串点号，你根本看不出那是旧值）；
2. 下次启动自动连接时，不管这份密码有没有被服务器认可过，直接拿去登录；
3. 登录失败后，内存里那个值还在，向导再开一遍，又被填回去。

结果就是：你以为每次重试发出去的都是刚敲的那份密码，实际上程序发出去的从头到尾是**同一个旧值**。
（这事能核对：拿失败日志里的摘要，用你正确的密码复算一遍，是对不上的。）

**改法**：

| 位置 | 现在 |
|---|---|
| 密码可信度 | 记录**是否被服务器验证过**，只有成功登录过才算 |
| 向导 | 有保存的密码时给「用已保存 / 重新输入」二选一，并标明“已验证 / 未验证” |
| 启动自动连接 | 复用前记录来源（本次输入 / 已保存已验证 / 未验证 / 上次被拒） |
| 服务器拒绝后 | 标记未验证 + 清空内存密码，逼向导重新询问 |
| 登录成功 | 标记该密码已验证 |

## 顺手一起收拾的

- 地址输入框换成了 AppKit 原生实现：现在**任意位置都能改、光标不再被踢到末尾**，Enter 还能一路跳到下一项；
- `ldap auth error` 会自动换个新 salt 再试 2 次（同一密码常常第二次就过了），而且**不再自动清掉你的密码**、也不再一股脑把锅甩给密码；
- 体检页：把"能不能上网"的排查并进「开始检测」，每个模块都会显示耗时，国家带上了国旗，IP 纯净度走多源交叉（ipinfo/ipapi/ipwho/BiliBili，可选 IP2Location/MaxMind），DNS 出口和 IP 出口也会拿来比对；
- 测速第三档会自动探测本地代理端口，你不用再手输；
- 状态不再灰→绿→红乱跳：以“最后一次真实探测”为准，官方客户端占着端口时就老实显示「已连接（官方客户端在管）」。

## 装上它

1. 解压后把 `JLU Gate.app` 拖进 `/Applications`（要是装过旧版，先把它退了再换）；
2. 第一次打开要是弹"无法验证开发者"：右键 → 打开就好；
3. 菜单栏冒出盾牌图标 → 填好账号密码。

## 卸载

双击包里的 `Uninstall JLU Gate.command` 就行——App、配置、日志、钥匙串条目，一并清掉。
