# JLU Gate 0.1.1

> 这是一个**稳定性修复版**，只解决登录流程里最要命的一个问题。

## 修复：密码被静默复用，导致“怎么点都连不上”

**症状**：密码明明输对了，服务器却一直回 `ldap auth error`；重启、重试多少次都一样。

**根因（我们自己的 bug）**：程序把“保存过的密码”在三处静默复用——

1. 向导打开时直接把它填进输入框（显示成点号，看不出是旧值）；
2. 下次启动自动连接直接拿它去登录，不管它是否被验证过；
3. 失败后内存里那个值仍在，向导再打开又被填回去。

于是每一次重试，发出去的都是**同一个旧值**，不是用户以为的那份密码。
（可核对：失败日志里的摘要，用正确密码复算是对不上的。）

**改法**：

| 位置 | 现在 |
|---|---|
| 密码可信度 | 记录**是否被服务器验证过**，只有成功登录过才算 |
| 向导 | 有保存的密码时给「用已保存 / 重新输入」二选一，并标明“已验证 / 未验证” |
| 启动自动连接 | 复用前记录来源（本次输入 / 已保存已验证 / 未验证 / 上次被拒） |
| 服务器拒绝后 | 标记未验证 + 清空内存密码，逼向导重新询问 |
| 登录成功 | 标记该密码已验证 |

## 其它一并修掉的

- 地址输入框改成 AppKit 原生实现：**任意位置都能改、光标不再被踢到末尾**，Enter 可一路跳到下一项；
- `ldap auth error` 会自动换新 salt 重试 2 次（同一密码也常常第二次就过），且**不再自动清除密码**、不再把原因归咎于密码；
- 体检页：能上网排查并入「开始检测」，每个模块显示耗时，国家带国旗，IP 纯净度多源交叉（ipinfo/ipapi/ipwho/BiliBili，可选 IP2Location/MaxMind），DNS 出口与 IP 出口比对；
- 测速第三档自动探测本地代理端口，不用手输；
- 状态不再灰→绿→红乱跳：以“最后一次真实探测”为准，官方客户端占端口时显示「已连接（官方客户端在管）」。

## 安装

1. 解压后把 `JLU Gate.app` 拖进 `/Applications`（如已有旧版，先退出旧版）；
2. 首次打开若提示“无法验证开发者”：右键 → 打开；
3. 菜单栏出现盾牌图标 → 设置账号密码。

## 卸载

双击包内 `Uninstall JLU Gate.command`，会删掉 App、配置、日志与钥匙串条目。
