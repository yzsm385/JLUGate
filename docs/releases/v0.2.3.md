# JLU Gate 0.2.3

> 学校的校园广告和登录门户，以前得自己翻地址；这一版让主面板直接把入口递给你——记得上次去过的就直接开，不记得就现场探一下再开。

- 主面板新增「看校园广告 / 门户」按钮；
- 有上次记下的门户地址 → 直接打开；
- 没有 → 现场做一次 captive 探测（`generate_204` / `connecttest.txt`），从 302 的
  `Location` 拿到今天的门户/广告地址，记下来并打开；
- 已经在线、学校不再弹时，明确提示"没探测到门户"，不会开空面板；
- 一切都在系统浏览器里打开，App 内不嵌 WebKit，也不会自动弹窗。
