# 学号前缀 → 学院/单位（检索用）

> 2026-11-05 初版。数据来自你给的学号名单（81 条），给 GPA/推免测算做「学号 → 学院」索引。
> 结构化数据：[data/student-id-prefixes.js](data/student-id-prefixes.js) / [.json](data/student-id-prefixes.json)；
> 可读表：[out/学号前缀_学院对照.csv](out/学号前缀_学院对照.csv)。

## 口径

1. **只是索引，不是培养方案。** 认出院系之后，还要有该院系的课程表/推免细则才能算 GPA；目前只有软件（55）和计算机（21）两套。
2. **本科与研究生基本共用同一套专业代码**（你 2026-11-05 说明）。所以代码只能回答「这个单位有没有本科」，不能回答「某个学生是不是本科」。
3. **只有 `undergraduate === true` 的条目才继续算绩点。** `false` 表示不招本科（行政单位、公共教学中心、继续教育、科研机构等），`null` 表示待确认、不猜。
4. **简称补全**：没写「学院 / 中心 / 学部 / 研究所 / 团委…」的，自动补「学院」。
   例外是固定写法：文学院、法学院、药学院、商学与管理学院、新闻与传播学院（直接补会变成「文学学院」）。
   已经含「学院」的（如「软件学院珠海」）不再补。

`32`、`33` 都写「口腔医」，按两码一院处理（不是冲突）。

`04` 只对应**艺术学院**；原名单里那条「04 三外国语」是误记，已删掉。外国语学院按 `03`（外国语言文化，别名外国语学院）处理。

同码**不替用户写死**：查询只给候选，界面让用户点一次；选过之后记在本机，下次直接命中。

```js
StudentIDIndex.resolveForGPA("25230123");
// { status: "needs-choice", options: [环境与资源学院, 新能源与环境学院] }

StudentIDIndex.rememberChoice("25", "25#2");   // 用户选了新能源与环境学院
StudentIDIndex.resolveWithSaved("25230123");   // → { status: "ok", entry: 新能源与环境学院 }
StudentIDIndex.forgetChoice("25");             // 换人/换学院时清掉
```

## 学号格式（已确认）

`21 23 01 23` = 代码 `21`（计算机）+ 入学年份 `23`（2023）+ 班号 `01` + 班内序号 `23`。

- 代码在最前面，2–4 位（`JX49`、`XZ27`、`199`…），按最长匹配。
- 所以 `20230123` 是 `20`（通信）+ 2023 级，**不是**「2020 年 + 23 学院」。
- 年份只用于展示；要不要算绩点只看代码。
- 同码（25 / 81）代码本身分不开，交给用户在候选里选，选过记住。

## 查询

浏览器里先引两个脚本：

```html
<script src="data/student-id-prefixes.js"></script>
<script src="assets/student-id.js"></script>
```

```js
StudentIDIndex.forStudentID("55230123");
// [{ offset: 0, codeLength: 2, year: "2023", code: "55", entry: { name: "软件学院", … } }]

StudentIDIndex.resolveForGPA("50230123");
// { status: "not-undergraduate", entry: { name: "预科教育学院", … } }
// status: ok / not-undergraduate / needs-confirmation / needs-choice / not-found

StudentIDIndex.resolveForGPA("25230123");        // 同码：给候选
// { status: "needs-choice", options: [环境与资源学院, 新能源与环境学院] }
StudentIDIndex.rememberChoice("25", "25#2");     // 选新能源与环境，记住
StudentIDIndex.resolveWithSaved("25230123");     // → ok，新能源与环境学院

StudentIDIndex.search("软件");     // 软件学院、软件学院珠海
StudentIDIndex.byCode("55");      // 按代码取（重复代码会返回多条）
StudentIDIndex.undergraduates();  // 53 条
```

匹配规则：长代码优先（`JX49` 先于 `JX`，`199` 先于 `19`），避免「软件学院珠海」被认成「软件」。
