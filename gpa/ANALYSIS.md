# 调研与核对记录（软件工程 2022 版）

本文件记录数据从哪来、怎么算、哪些地方是估算，方便下一轮扩展到其他专业时复核。

## 1. 培养方案

- 来源：[软件学院本科培养方案（2022 版，修订版）](https://csw.jlu.edu.cn/info/1080/7353.htm)，2024-09-04 发布，附件 PDF 24 页。
- 毕业总学分 169：课程教学 126.5 + 实践教学 42.5；其中必修课程 106 学分。
- 软件工程专业指导性教学计划见 PDF 第 4–8 页；数据科学与大数据技术见第 18–21 页；工科试验班（软件工程）见第 12–14 页。
- 页面仅提供合并后的学分（如“微积分 AⅠ–Ⅲ 10 学分”“体育Ⅰ–Ⅳ 4 学分”），本工具按常见分配拆分展示：
  - 微积分 AⅠ/Ⅱ/Ⅲ：3.5 / 3.5 / 3
  - 体育Ⅰ–Ⅳ：1 / 1 / 1 / 1
  - 大学英语 BⅢ/Ⅳ：2 / 2（2022 级科目表列在大一上）
  - 形势与政策Ⅰ–Ⅲ：0.5 / 1 / 0.5
  - 劳动教育（上/下）：1 / 1
  - 军事理论（上/下）：1 / 1
- 拆分只影响学期维度展示；总学分与总 GPA 权重仍按培养方案原学分。

## 2. 推免规则（2022 级参考）

来源：[《软件学院推荐 2026 年优秀应届本科毕业生免试攻读研究生实施细则》](https://csw.jlu.edu.cn/info/1095/7937.htm)（2025-08-25 公示，DOCX 附件）。

关键条款：

- 学业成绩 = 前三学年培养方案**全部必修课程（含实践教学环节）**的平均学分绩点。
- **限选课程不计入**（见同页附件 3《限选课成绩不计入学业成绩的公示》）。
- **体育、军事理论、军事训练不计入**；大学英语仅Ⅲ、Ⅳ计入。
- 成绩以**第一次考试**为准；重修、刷分不参与排名；缓考/补考按第一次成绩。
- 综合成绩 = 学业 GPA + 素质类加分，加分上限 **0.4**；同分按学业成绩排序。
- 软件工程选拔线为专业**前 30%**；数据科学与大数据技术为前 25%。
- 申请普通推荐要求 GPA ≥ 2.5；外语需校内必修英语均分 ≥ 75 或四级 ≥ 425。
- 普通推荐**允许最多 1 门**必修/限选不及格，但须在推免前重修通过；2 门及以上不符合条件。排名仍按第一次成绩。
- 2026 年学院拟推荐共 89 人（软件工程 76 + 大数据 13），备选 17 人（软件工程 14 + 大数据 3）。

### 95.5 学分的推导

| 项 | 学分 |
| --- | ---: |
| 培养方案必修课程 | 106.0 |
| − 体育Ⅰ–Ⅳ | −4.0 |
| − 军事理论 | −2.0 |
| − 大学英语Ⅰ/Ⅱ | −4.0 |
| − 劳动教育（2022 级科目表未列） | −2.0 |
| + 企业实训（必修实践，第 5 学期） | +1.5 |
| **推免学业成绩合计** | **95.5** |

对应 40 门。企业实训已确认计入；劳动教育在 2022 级科目表中未列，故 2022 级不计入。**2022 级只作参考，不能照搬**：2023 级起劳动教育、企业实训、国家安全教育都计入；但 2023/24/2025 官方课程表未发布，97.5 / 98.5 只是已知差异推算。2026 级方案未发布。毕业设计（第 7–8 学期）、企业实习、专业选修、限选课、公选课均不在内。

## 4. 绩点换算

本工具采用校教字〔2016〕110 号的 10 档：

| 百分制 | 绩点 |
| --- | ---: |
| 90–100 | 4.0 |
| 87–89.9 | 3.7 |
| 84–86.9 | 3.3 |
| 80–83.9 | 3.0 |
| 77–79.9 | 2.7 |
| 74–76.9 | 2.3 |
| 70–73.9 | 2.0 |
| 67–69.9 | 1.7 |
| 64–66.9 | 1.3 |
| 60–63.9 | 1.0 |
| < 60 | 0（挂科） |

- 单门课绩点固定 1 位小数；最终 GPA 保留 6 位小数。
- 按 0.1 分精度判定：89.9 仍是 3.7，工具会打“卡绩”标签，并估算这批课升档可拉回的 GPA。
- 备注：成绩单矩阵里出现的 1.0 / 1.3 / 1.7 正好对应 60–69 分的旧档，和 2016 文件、参考项目一致；60 以下才是挂科（0）。若教务系统显示不同，以系统为准。
- 参考项目 [dailypotato/JLU-GPA-Calculator](https://github.com/dailypotato/JLU-GPA-Calculator)（v1.0.1）：没有软件工程课程表，保研课程规则为空/未核验；它的分数—绩点映射也是旧 10 档（70–73=2.0、67–69=1.7、64–66=1.3、60–63=1.0），与 2022/2023 成绩单矩阵和本工具一致。

## 5. 成绩单矩阵核对

本地保研目录 `"/Volumes/계연 SD/Doc/Further/吉大/保研/"` 里找到了计算机学院 2022 级的逐门成绩单矩阵：

- `2022计算机.xlsx`：43 门课、102.5 学分；最后一列 GPA 与按列学分加权的结果完全一致（宋乃钦 3.94976、武锦旗 3.89317 等）。
- 矩阵包含：劳动教育 2、思想政治理论课实践教学 2、企业实训 1、形势与政策 2、大学英语Ⅲ/Ⅳ 4。
- 矩阵不包含：体育、军事理论/军训、大学英语Ⅰ/Ⅱ、毕业设计、专业选修/公选。
- `2022物联网.xlsx`（46 门）、`2022网安.xlsx`（40 门）、`2022唐班.xlsx`（40 门）结构相同。
- `2023计算机.xlsx`（347 人）也是同样的课程列结构。

这印证了“必修 + 实践环节，排除体育/军事/英语Ⅰ/Ⅱ”的大口径，但 **计算机学院不等于软件学院**：计算机的 43 门课表不能直接套到软件工程。软件工程这边，你提供了 2022 级官方 40 门 / 95.5 学分表，已据此修正：劳动教育不计入、企业实训计入。

另外，矩阵里 1.0 / 1.3 / 1.7 出现得很多，这正是旧 10 档里 60–69 分的正常低分档；60 以下才是挂科（0）。普通推荐允许 1 门挂科，但排名按第一次成绩。

## 6. 核对结果

- 40 门计分课合计 95.5000 学分（`build_data.py` 内有断言）。
- 示例成绩（大一至大二 31 门，77.0 学分）加权 GPA = **3.566883**，与页面一致。
- 边界测试：65→2.0，73→2.0，74→2.3，77→2.7，80→3.0，84→3.3，87→3.7，90→4.0；89.9→3.7 并触发卡绩；59.9→0 并触发挂科。
- 目标反推：示例状态下，剩余 18.5 学分需平均 3.015 可达 3.46。

## 9. 加分规则（2026）

- 五类、同类取最高、跨类累加、总分上限 0.4。
- 竞赛 A/B/C 分值来自 2026 软件细则 DOCX；A/B/C 等级用官方《学科竞赛体系（2022）》XLSX 匹配，不靠图片 OCR。
- 科研（大创/论文）来自 2026 软件细则 DOCX；论文要求第一作者、第一单位吉林大学软件学院。
- 参军 0.2+0.2、上限 0.4 来自 2022 学工部细则；该细则写明适用于 2021 年（含）前入伍，当前届需确认。
- 志愿服务/国际组织实习：2026 软件细则只列类别，未给分值；公开材料未找到分值表，暂不填。
- 2026 实际：375 人中 36 人有加分，最高 0.2；同项取最高、跨项累加在实际名单里可验证。
- 详细表见 `BONUS_RULES.md` 与 `out/软件工程2026_加分细则.xlsx`。
